# Village Observer V0.34G3 — 정착지 원형 확장 + 기아 임박 구호

기준선: **V0.34G2A**. G2B 식량 구호 안정화는 별도 버전 없이 G3에 포함한다.

## A. 정착지 실제 공간

- `Tile = 타일`, `Settlement = 정착지` 개념을 유지한다.
- 병합 가능성: **유클리드 원형 반경 안 AND 실제 정착지 소속 타일을 경유한 중심지 왕복 최단 통행비가 제한 안**이어야 한다. 도로 보정(0.62), 지형 비용, 도로 상태 25 미만 비활성, ROADS 기술, 국가 소유권, 인접성, 90일 병합 대기 및 180일 분할 유예는 그대로다.
- 성장단계: 초기 **반경 R2 / 13타일 / 병합 비용 1.24**. 구성 타일의 주민 **12명 이상 + 실건물 2개 이상**이면 **R3 / 29타일 / 3.10**. 주민 **30명 이상 + 실건물 6개 이상**이면 **R4 / 49타일 / 4.34**. 분할 허용 비용은 기본 1.40, 성장단계 3.45/4.69. 원 안에 있어도 우회 통행비가 초과하면 합치지 않는다.
- 시설·인구로 달성한 성장 단계는 분기별 정착지 검토 시 `v034g3MaxTier`로 기록하여 인구가 일시적으로 줄어든 것만으로 대형 정착지가 즉시 붕괴하지 않도록 한다. 물리적 연결/도로가 끊기면 기존 분할 유예가 적용된다.
- 개척 후보의 compact frontier 보너스 +14는 동일 원형 반경과 확장 단계/예상 진입 비용에 맞춰 점검한다. 개척 타일의 도로는 *예상 점수용*이지 실제 건설되는 것은 아니다. 병합은 반드시 실제 도로로 판정한다.
- 경로비 검사는 양방향 Dijkstra를 사용하여 기존 노드당 반복 최단경로 탐색보다 경량화했다. C1H 보호 169개 파일은 바꾸지 않고 **빌드 산출물의 C(154) 코드를 검증된 앵커에서 변환**한다.

## B. 기아 임박 구호 안정화

- G2A의 정착지 단위 실제 식량 재고·나이별 수요, 3일 주기, 배송마다 공급원 재계산·비축량 재검증·출고입고 보존을 유지한다.
- 정상/위기 구호 **24/40작업주기 하한은 유지**. 다만 **Hunger ≥95 주민이 있으면서 해당 정착지 비축 <3 작업주기** 또는 **Hunger ≥85 주민이 있으면서 비축 <1.5 작업주기**인 *기아 임박 정착지*만 별도 처리한다.
- 긴급 하한 **18작업주기**를 허용하려면 국가 합산 식량이 국가 합산 한 주기 수요의 **20배 이상**이고, 해당 국가에 **Hunger 85 미만이며 18작업주기 이상 보유한 안전 공급원**이 있어야 한다. 그 외에는 기존 24/40 기준을 적용한다.
- 긴급 구호에서는 더 낮은 정착지 비축과 개인 Hunger 급박성을 먼저 평가한다. 기본 4곳/국가/3일, 정착지당 공급원 최대 5곳, 실제 물류 경로비/저장용량/장비 없는 배송 금지를 유지한다.
- G3 배송 CSV에서 `reliefMode` (`STANDARD`/`IMMINENT`)와 `reliefFloorCycles` (24/40/18)를 추가하며, `worldSummary.v034g3`에서 비상 구호 횟수·양과 공간 단계 관측치를 제공한다.

## C. 빌드와 실행

```
npm run build
npm run test:static
G3_DAYS=900 node tests/test-g3.cjs
python tests/browser-g3-smoke.py
```

- `dist/standalone/index.html`: 단독 실행 파일.
- `dist/hosted/index.html` + assets: PC/모바일 Github Pages용 파일.
- 루트 `index.html`은 Hosting용이고, `index-standalone.html`은 단독 실행용이다.
- 과거 G2A 저장 파일을 G3로 가져올 수 있다. G2A로 되돌리면 G3 공간/구호 변경 및 저장 메타데이터의 하위 호환을 보장하지 않는다.

## D. 검증 원칙·미검증 범위

- 공간 변경만 활성화한 경우, 구호 변경만 활성화한 경우, 두 가지를 함께 적용한 경우를 구분해 통제 시험할 수 있다 (`NS.V034G3.config.spatialEnabled`, `.foodEnabled`; 개발/테스트 플래그, 일반 플레이 UI에는 노출하지 않음).
- 정착지 원형 범위/반경 크기 및 도로 누락, 구호 초과배송/총량 불변, 후속 저장/불러오기, 긴급 조건 미충족 차단을 자동 회귀로 점검한다.
- **장기 사용자 60년차 G2A 세이브 파일은 제공되지 않았다.** 60년 DEVLOG/CSV로부터 똑같은 시점의 RNG 세계를 재구성할 수 없다. 30~60년차 실제 패치 검증은 사용자 자연주행이 필요하다.
- 국제 무역, 국내 상업 거래, 군사 AI, 전투 및 F3 신진대사 자체는 수정하지 않았다.
