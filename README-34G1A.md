# V0.34G1A — 정착지 UI 분리 + 식량 물류 감사 연결 안정화

**기준: V0.34G1 · 제작: 2026-10-16 · G1A는 관측/UI 전용**

## 변경점

1. 국가 > 정착지 화면에 **정착지 / 타일** 하위 탭 도입.
   - **정착지**: 실제 D2 정착지 레지스트리 기준으로 카드 1개/정착지. 인구·공동 주거·공동 식량/비축 주기·목재·석재·건물 수·주거 부족·구성 타일을 표시. 카드를 펼쳐 구성 타일 클릭 시 **타일** 탭으로 전환하며 기존 상세 페이지를 유지. 지도 이동 버튼 제공.
   - **타일**: G1까지의 기존 전체 타일 목록, 물리 재고, 건물·현장 정보, 기존 상세 구성과 지도 타일 검사기 보존.
2. **G1 물류 감사 CSV가 자연주행에서 헤더만 나오던 현상 안정화**:
   - `World.advanceOneDay`가 완료된 후 달력 6일 간격으로 **독립적인 정착지-타일 수요 비교 샘플** 실행. 기존 E2 식량 판단 및 RNG에 영향 없음.
   - 실제 `NATIONAL_FOOD_RELAY32D5` 텔레메트리 이벤트를 별도로 포착해 출발/도착 정착지 ID, 동일 정착지 여부, 물리 타일 ID 기록. 기존 G1의 E2 Pair 캐시미스 관측을 G1A 독립 계수에 추가.
   - `G1A 물류 감사 CSV` 버튼은 새로운 G1A CSV(30열, 제한 1600행)를 추출. Devlog `worldSummary.v034g1a`에 카운터 별도 추가. 기존 `worldSummary.v034g1`는 비교용으로 유지.
   - 비어 있는 신규 세계(다중 타일 정착지가 아직 없거나 식량 보급 이벤트가 없는 시점)는 신규 CSV에도 샘플 상세행이 0개일 수 있다. **`sampleDays>0`이 감사를 실제 실행했다는 증거**다.
3. G1A의 `sameSettlementShipments`는 텔레메트리 이벤트 시점에 실제 정착지 ID로 판별하므로 사후 타일 소속에 의존한 G1 분석을 개선한다.

## 모델 미변경 원칙

- 정착지 공동 재고, 생산, 배급, 식량 운송 선택·운송량, AI, 주민 신진대사·행복·건강, Gold 회계, 전쟁과 RNG 사용량 **변경 없음**.
- 아직 식량 수요를 정착지 단위로 실행하는 수정은 하지 않았음. 이는 **V0.34G2** 작업이며, 출발/도착 가능한 타일의 실경로 기반 선정도 G2의 과제다.
- 감사 기록은 매번 실행 중 World 객체에만 저장되고 **일반 세이브에 저장되지 않는다**. 불러오기 후부터 다시 샘플링한다.
- **G1A 관측 범위**는 E2 식량 구호 비교와 실제 `NATIONAL_FOOD_RELAY32D5` 이벤트이다. 외교 교역, V27/V28 및 일반 상업 거래 전체는 제외된다.
