# Village Observer V0.28

Village Observer는 실제 주민(Person)의 생활과 선택이 **Settlement → Nation → World** 변화로 이어지는 browser-based bottom-up 사회 시뮬레이션입니다.

V0.28의 주제는 **후기 정착구조·도시화 V1**입니다.

V0.27 장기주행에서 19×19 자연 타일이 이미 완전히 점유된 뒤에도 인구가 약 63년 884명에서 111년 5,651명까지 계속 증가했습니다. 동시에 통근자, 주거 압력, 내부 물류가 크게 늘었고, 국가 전체 식량은 충분해도 특정 지역에서 기아가 재발했습니다.

따라서 V0.28은 영토를 더 넓히는 시스템보다 **이미 확보한 영토 안에서 사람·일자리·주거·식량이 어디로 모이고 흩어지는가**를 시뮬레이션합니다.

---

## 1. Person 기반 국내 이주 V2

기존 `homeTileId` / `workTileId` 구조를 유지하면서, Person의 국내 이주 판단을 다시 구성했습니다.

이제 이동 후보지는 다음 요소를 함께 평가합니다.

- 실제 주거 여유
- 해당 정착지의 식량 비축일
- Person 직업과 지역 자원/시설의 적합도
- 시장·상업·행정·교육 등 서비스 시설
- 실제 통근 유입
- 도로 존재
- 가족·관계 인물의 거주지
- 국가 AI 성향

마지막 주민을 빼내 정착지를 비우는 이동은 계속 금지합니다.

이동은 Person 개체를 삭제하거나 숫자로 옮기는 방식이 아니라, 실제 Person의 `homeTileId`가 변경됩니다.

### AI 성향 차이

- **도시집약형:** 이미 일자리와 서비스가 집중된 중심지에 추가 가중치
- **교역외교형:** 시장·교역소·상인조합·항구가 있는 곳 선호
- **생존안정형:** 식량 안정과 주거 여유를 더 중시
- **영토확장형:** 수도 과집중을 다소 덜 선호
- **자원개척형:** 목재·석재 자원이 좋은 정착지에 추가 가중치

## 2. Emergent 도시성(Urbanity)

V0.28은 AI가 임의로 “도시를 건설”하지 않습니다.

각 Settlement의 실제 상태를 관찰해 **도시성 점수**를 계산합니다.

주요 입력값:

- 실제 주민 수
- 실제 근무자 수
- 통근 유입
- 시장·교역·행정·교육·항구 등의 서비스 시설
- 주거 점유율
- 도로
- 중심지 여부

도시성은 관찰용 지표이며, 등급 자체가 보너스를 생성하지 않습니다.

표시 등급은 절대 인구 조건과 도시성을 함께 사용합니다.

- 촌락
- 마을
- 소도시
- 도시

초기 15~20명짜리 중심지가 시설 몇 개만으로 곧바로 “도시”가 되는 현상을 피하기 위해 절대 인구 기준을 함께 적용합니다.

---

## 3. 생활권(Life Zone) V1

여러 Settlement가 실제로 하나의 생활권처럼 작동하는 현상을 관찰합니다.

생활권 연결은 주로 다음으로 형성됩니다.

- 실제 Person 통근 연결
- 서로 인접한 고도시성 Settlement
- 가까운 강한 중심지 간 연결

생활권은 **행정구역이 아닙니다.**

기존 Settlement는 그대로 남으며 Person과 건물도 합쳐지거나 삭제되지 않습니다.

행정적인 City / Administrative Area 통합은 향후 V0.30의 영역입니다.

---

## 4. 주거 압력 → 실제 고밀도화

V0.27의 장기 데이터에서는 후기 인구의 상당수가 housing strain 상태에 들어갔습니다.

V0.28에서는 높은 주거 점유율이나 실제 주거 부족이 감지되면 도시화 시스템이 기존 건설 시스템을 통해 대응합니다.

우선순위:

1. 기존 주택의 실제 개축
   - 주택 → 연립주택
   - 연립주택 → 집합주택
2. 실제 주택 신축
3. 공간이 부족하면 실제 토지 정비

모든 행동은 기존 기술 요구량, 자원비용, 노동일, 건축공간, 공사 프로젝트 한도를 그대로 사용합니다.

도시집약형 국가는 다른 성향보다 주거 압력에 조금 더 빠르게 반응합니다.

## 5. 후기 식량 접근성 보강

V0.27의 물리적 내부 식량 수송은 그대로 유지합니다.

V0.28은 특히 인구가 집중된 지역에서 다음 상황을 더 빨리 감지합니다.

- 지역 식량이 약 12일 미만
- 심각한 Hunger Person 존재
- 정착지 평균 Hunger 급상승

이 경우 더 넓은 donor 정착지 집합을 확인하고, 도시 중심지·도로 연결 지역에는 한시적으로 더 큰 **실제 내부 운송 용량**을 사용할 수 있습니다.

중요한 점:

- 식량을 생성하지 않음
- 국가 공용창고에서 순간이동하지 않음
- 실제 donor Settlement의 stock에서 빠짐
- 실제 receiver Settlement의 stock으로 들어감
- 실제 내부 경로가 있어야 함
- donor도 최소 비축량을 남김

심각한 지역인데도 운송 가능한 donor가 없으면 `V28_FOOD_ACCESS_BLOCKED` 로그를 남겨 후기 기아 원인 분석이 가능하도록 했습니다.

## 7. UI

국가 개요 하단에 **V0.28 도시화·생활권** 패널이 추가됩니다.

표시값:

- 최대 정착지 인구
- 상위 3개 정착지 인구 비중
- 정착지 인구 Gini
- 통근자 수/비율
- 소도시/도시 수
- 생활권 수
- 주거 압박 인구
- 식량 스트레스 인구
- 현재 가장 강한 중심지

정착지 카드에는 추가로:

- 촌락/마을/소도시/도시 등급
- 도시성 점수
- 근무자 수
- 통근 유입/유출
- 주거 점유율
- 지역 식량 비축일

을 표시합니다.

## 8. 저장 호환

V0.28 저장 키:

`village-observer-v0-28`

기존 V0.27 이하 저장을 fallback으로 불러올 수 있습니다.

V0.28 추가 누적 통계도 저장/재로드됩니다.

개발 로그/스냅샷 파일명 역시 `v028`로 출력됩니다.

## 9. 회귀 테스트

V0.28 개발 중 다음 항목을 확인했습니다.

- 전체 inline JavaScript 문법 검사 통과
- 브라우저 실제 로드 성공
- V0.28 title/runtime HUD 정상
- 20년 장기 headless 진행에서 runtime exception 없음
- 6개 국가가 테스트 종료 시점까지 유지
- Person Health/Hunger/Energy/Happiness NaN 미발견
- 음수 Settlement stock 미발견
- V0.28 저장 → 재로드 → V0.28 재저장 정상
- V0.27 형식 저장 데이터를 V0.28로 마이그레이션 가능
- snapshot CSV 모든 행의 열 개수 일치
- V0.28 도시화 지표가 JSON/CSV에 정상 추가됨

장기 밸런스는 랜덤 세계와 AI 선택에 따라 달라질 수 있으므로, 다음 단계는 실제 플레이에서 60~100년 데이터를 다시 수집해 **도시 집중도·주거압력·기아 재발·통근 구조**를 비교하는 것입니다.

---

## 10. V0.28에서 의도적으로 하지 않은 것

V0.28은 도시화의 사회·공간 기반만 만듭니다.

아직 하지 않습니다.

- Settlement의 행정적 합병
- City / Administrative Area의 공식 통치 계층
- 본격적인 국가 내부 세금·도시재정 재설계
- 철광석/제련/철제품
- 군대·징집·전쟁

현재 로드맵에서는 각각 이후 V0.29~V0.32 단계에서 확장합니다.
