# Village Observer V0.34D3A2 — Frontier Food Accounting Hotfix

**버전:** V0.34D3A2 (2026-10-11)  
**기준선:** V0.34D3A1  
**성격:** 식량 회계·관측 전용. 시뮬레이션 밸런스·AI 결정·난수 소모·물리 자원 이동 공식 변경 없음.

## 패치 배경

D3A1 자연주행(약 5년)에서 Food Flow 구간 가운데 Settlement 구성이 그대로인 151개 행에서 약 164.61의 음수 잔차가 관측됨. 그중 -0.96, -0.64, -1.60과 -4.xx 패턴은 V0.20 개척 진행의 직접 국가 식량 차감과 개척 중 보급 사고 식량 차감과 일치하는 구조였음.

이 수치는 **기존 관측 자료에서 재현된 미설명 감소**이지 D3A2 실측 후 완전히 소거됐다는 증거가 아님. D3A2의 동일 원인 합성/실제 함수 회귀시험에서 정확한 회계를 확인했으며, 5년 자연주행 재검증은 아직 남음.

## 변경사항

1. `src/legacy/029.js`의 `progressFrontiers20` 식량 유지비 `0.032 × 실제 활동 개척민 수`를 차감하기 전후, 국가 소유 타일별 **실제 재고 차이**로 계측. 코드상 비용 추정치를 실제 차감량으로 오인하지 않음.
2. 같은 함수의 V20 개척 보급 사고에서 요청 식량 최대 4를 실제 재고 차이로 별도 계측. 국가에 재고가 4 미만이라면 실제 감소한 만큼만 기록.
3. Food Flow 기본 `frontierFoodSpent`는 개척 착공비 + 개척 진행 유지비 + 보급 사고 비용을 포함. 두 신규 열은 그중 유지비·사고비의 **세부 구성**이며, 총 식량 수지에서 재차 빼지 않음.
4. Food Flow 30일 CSV에 `frontierFoodUpkeep`, `frontierFoodAccident`를 추가: 46열 → **48개 고유 열**. D3A1 본래 CSV 46열을 수정하지 않고 D3A2 CSV 내보내기에만 확장.
5. Devlog에 `v034d3a2Audit` (유지비/사고 실제 차감 총량, 이벤트 수, 새 열 수, 재고 감사) 추가.
6. 새 저장 키 `village-observer-v034d3a2`, 저장/복원 및 수동 JSON 불러오기: D3A2, D3A1, D3A 입력 지원. 구버전 저장의 과거 관측 구간은 소급 재분류하지 않음.

## 변경하지 않은 것

- 자연 식량 회복, 채집 생산량, Person 식량 소비, 경제/국제교역 및 가격, 주거 정책, 군사, 골드.
- 개척 착공 자재/골드/식량 비용, 유지비 `0.032`, 위험확률 및 사고 손실 `4`, 개척 기간, 난수 사용량.
- 다른 Settlement 간 실제 물류 제약, 물리 타일 재고.
- 169개 레거시 원본 블록 (빌드 단계에서 정확히 두 곳만 변환).
- 기존 CSV: Snapshot V2 1,683열 / Settlement 48열 / Housing 11열 / Economy 24열.

## 필수 검증 포인트

Food Flow CSV의 `frontierFoodSpent`는 **착공비 + 유지비 + 사고비 전체**이므로 `frontierFoodUpkeep` 및 `frontierFoodAccident`를 다시 빼면 중복 계상이다.

변경 전 D3A1과 같은 시드·같은 난수 초기 상태로 실제 70달력일을 주행하면 **물리 상태와 난수 소모 32,041회가 일치**한다. 이 비교는 70일 조건의 회귀 결과로서 장기 동일성을 증명하지 않는다.

5년 자연주행 자료에서 기존에 남았던 -164.61 잔차가 같은 규모로 다시 나타나는지 30일 Food Flow의 `unattributedDelta` 열을 기준으로 확인할 것. 구성 변경 `topologyChanged=1`인 행은 수지 판정에서 제외할 것.

## 제약·열린 문제

- V20 경로의 유지비·사고비를 정확히 계측. 다른 역사적 개척 경로의 미검증 직접 차감이 없다고 단정하지 않음.
- 초기 5년 자연주행을 완료했다고 주장하지 않음. D2B 고정 시드의 장기 중단 원인, 후기 60~75년, 전쟁·점령 중 경제 감사는 여전히 검증 대상.
- 지역적 식량 생산 노동 부족(에브), 반복 주거 착공 검토와 노동 슬롯 구조 경고 등은 이번 패치 범위 밖.
- 종료 시점 전에 저장된 구버전 30일 행에는 새 열이 소급 생성되지 않는다. 구버전 부분 구간을 이식하면 해당 구간의 감사잔차는 현 버전 이후 부분만 보정됨.
