# V0.34C1H — Maintenance Finalization Hotpath + C-Series Closure Candidate

**배포:** 2026-10-10  
**기준선:** V0.34C1G  
**범위:** V0.25 분기 건물 유지보수 정산의 반복 행정권 조회 재사용 및 유지보수 상세 성능 계측. 이 버전은 C1 계열의 **마지막 성능 패치 후보**이며, 사용자 실제 자연주행 검증 이후 C 계열을 공식 마감할 계획입니다.

## 1. 변경 내용

### 분기 정산 1회 범위의 행정 모델 재사용
- 기존 C1A는 `routeWithdraw25()`의 *자재 인출 한 번* 안에서 `NS.V032D.adminModel()` 결과를 공유했습니다. C1H는 **같은 국가의 `finalizeMaintenancePlan25()` 정산 한 번** 안에서 동일 결과를 공유합니다.
- 우선순위가 정해진 `maintenancePlan25.orders` 처리 순서와 각 자재의 로컬 인출 → 원격 공여자 탐색 → 실제 `withdrawAt()` 이동 순서는 유지했습니다.
- V0.32E10 공여자 후보 목록/경로 캐시, 기존 물류 수용량·도로 비용, 국가 간 물자 이동 및 Gold 흐름은 변경하지 않습니다.
- 이 임시 캐시는 정산 완료 후 폐기됩니다. 국가 간, 분기 간, 세이브 파일 간에 데이터를 공유하지 않습니다.
- 주의: 행정권 모델은 복합적인 레거시 진단 경로이므로, 향후 일부 건물·행정 구조가 정산 도중 바뀌는 드문 경우에 대한 자연주행 회귀 점검을 계속 권장합니다.

### 성능 계측
- C1B 정밀 분기 프로파일링 **ON**: `finalizeMaintenancePlan25()` 전체 시간, 자재 인출 누적 시간, 최초 공여자 후보 구축 시간, 국가별 정산 이력(최근 최대 112회)을 기록합니다.
- OFF: 고비용 시간 측정 없이 `finalizes`, `orders`, `withdraws`, `donorBuilds`, `donorEvaluations`, `adminScopesCreated`, `adminScopeReused` 정수 카운터만 기록합니다.
- Devlog: `worldSummary.v034c1hPerformance`, `worldSummary.v034c1hQuarterHistory`.
- Snapshot CSV: 12개 열 추가, **1,671 → 1,683열**. 국가 7행 × 스냅샷 시점을 맞추는 HF1 방식 유지.
- `withdrawalMs`와 `donorMs`는 `finalizeMs`에 포함되므로 **서로 더해 전체시간으로 계산하면 안 됩니다.**

- 유지보수 공여자의 기존 정렬·용량·재고·인출 순서 및 노동자 임무.
- 개척·경제·AIProfile·국제교역·생존·전쟁·장비 회수/유실·Gold 회계.
- 세이브 형식과 기존 `C1G` 및 이전 세이브 로드 경로. C1H 세이브는 `village-observer-v034c1h` 로컬 키를 사용하며 이전 버전 로드로 폴백합니다.

동일한 합성 61년 세계, 동일한 버전 간 세이브, 7개국, 3회 연속 유지보수 계획·정산. Node/V8에서 **C1G → C1H** 비교.

- 밀집 세계에서 캐시 재사용이 발생하고 반복 2·3회에 큰 절감이 관측됐습니다. 첫 실행·작은 국가의 절감은 불규칙합니다.
- **실제 61년 세이브의 처리시간 개선율이나 전체 Wall 감소를 확정하는 자료가 아닙니다.** 워밍업·실행 환경 및 합성 시설 배치의 영향을 받습니다.
- 정밀 OFF 직접 비교도 3회씩 상태·난수 일치. 100일 자동 주행(정밀 ON)은 분기 경계를 포함해 매일 상태·난수 일치. 75일 자동 주행(OFF)은 관측 구간 내 일별 상태·난수 일치.
- 초기 원본 C1G와 C1H의 일별 상태 비교에서는 실행시간을 기록하는 **기존 계측 메타데이터**가 달랐습니다. 그러한 시간값을 제외한 물리·논리 저장 상태를 비교했습니다.
