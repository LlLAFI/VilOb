# Village Observer V0.22

Village Observer는 실제 주민(Person)의 생활과 선택이 **Settlement → Nation → World**의 변화로 이어지는 bottom-up 자율 사회 시뮬레이션입니다.

V0.22는 V0.21의 100×100·19×19 장기 테스트를 바탕으로 다음 네 축을 적용합니다.

1. **장거리 발견·시장 접촉·교역(B축)**
2. **고출산·고사망형 전근대 인구동학 1차 개편**
3. **병렬 개척 프로젝트의 지도 시각화 복구**
4. **물류 지도 흐름을 하늘색·파란색 계열로 통일**

V0.21에서 적용한 확장 밸런스, 런타임 캐시, 계층형 devlog snapshot 정책은 그대로 유지됩니다.

---

## 1. 장거리 발견·접촉·교역

### 접촉을 4단계로 분리

국가 관계를 더 이상 단순히 `교역 가능 / 불가능`으로만 보지 않습니다.

1. **미발견**
2. **문명 발견**
3. **시장 정보 접촉**
4. **실제 교역 가능**

V0.22에서는 각 국가가 `contactNetwork22`에 다른 국가와의 접촉 수준과 최초 발견/시장접촉/교역 시점을 기록합니다.

새 telemetry 이벤트:

- `CIVILIZATION_DISCOVERED`
- `FOREIGN_MARKET_CONTACT`

국가 개요에는 `발견 / 시장정보 / 실제 교역가능` 국가 수가 표시됩니다.

### 거리 증가 방식

기존 근거리 교역을 없애지 않고 다음처럼 확장합니다.

- 기본 교역 가능 거리는 **약 1.34배**로 소폭 증가
- `사절단(ENVOYS)`은 발견·접촉과 실제 교역거리 보조
- `장거리 상단(LONG_DISTANCE_TRADE)`은 발견 범위·시장 접촉 범위·실제 교역거리를 크게 증가
- `항해술 / 원양 항해`는 이후 더 먼 해상 문명 접촉에 추가 기여

즉 작은 19×19 맵에서 이미 가까운 국가끼리 잘 거래하는 구조를 크게 망가뜨리지 않으면서, 100×100 같은 대형 맵에서는 기술 발전 후 일부 원거리 국가부터 경제권이 연결되는 방향입니다.

장거리 기술이 있다고 해서 전 세계가 즉시 연결되지는 않습니다. 실제 경로비용과 시장 접촉 단계가 모두 충족되어야 합니다.

## 2. 전근대 인구동학: 많이 태어나고 많이 죽는 사회

V0.21 장기 테스트에서는 순인구 자체보다 **출생과 사망의 절대 규모가 지나치게 작다**는 문제가 확인되었습니다.

V0.22의 목표는:

> 높은 출생률 + 높은 영유아/질병/아사 사망률 → 낮은 초기 순증가  
> 물류·보건 기술 발전 → 사망률 하락  
> 출생률은 한동안 높은 상태 유지 → 인구 급증

입니다.

### 출생

- 가임 여성: 대체로 17~42세
- 남성 파트너 풀: 17~55세
- 국가·지역 식량, 건강, 행복, 주거 혼잡도에 따라 연간 출생 확률 변화
- 기존보다 훨씬 높은 출생 기회를 가짐
- 출산 cooldown도 전근대 다산 가족이 나타날 수 있도록 짧아짐
- 주택이 다소 붐비더라도 출생이 완전히 차단되지는 않고 확률이 낮아지는 방식

### 연령별 사망 위험

질병·쇠약 사망은 연령에 따라 다릅니다.

- **0~1세:** 가장 높은 질병/쇠약 위험
- **2~5세:** 높은 아동 사망 위험
- **6~14세:** 성인보다 높은 위험
- **성인:** 비교적 낮지만 지역 식량·건강 상태에 따라 사망 가능
- **고령층:** 질병과 별도로 노환 위험 증가

아사도 국가 총식량이 아니라 **실제 거주 정착지의 식량 비축과 개인 hunger 상태**를 중요하게 봅니다.

따라서 국가 전체에는 식량이 많아도 교통·물류가 나쁜 변경에서는 사람이 굶을 수 있습니다. 이것은 전근대 물류 한계를 표현하는 의도된 현상입니다.

### 기술 발전과 사망률 감소

다음 발전은 사망 위험을 실제로 낮춥니다.

- `CART` — 지역 식량 공급 안정성 소폭 향상
- `ROADS` — 아사 위험 감소
- `FRONTIER_LOGISTICS` — 변경 보급 실패 완화
- `FOOD_PRESERVATION` — 식량 관련 사망 위험 완화
- `SANITATION` — 질병·영유아 사망 위험을 크게 감소
- `PUBLIC_WORKS`, `EDUCATION`, `URBANIZATION` — 질병 위험 추가 완화

따라서 기술은 단순 경제 보너스에 그치지 않고 **실제 Person의 생존확률**에 영향을 줍니다.

### 새 인구 telemetry

국가별 누적값:

- `births22`
- `childDeaths22`
- `starvationDeaths22`
- `illnessDeaths22`
- `oldAgeDeaths22`

국가 개요에도 누적 출생 / 사망 / 아동사망이 표시됩니다.

## 3. 개척 점선 시각화 수정

V0.20 이후 실제 개척은 `expansionProject` 하나가 아니라 `frontierProjects[]`의 병렬 프로젝트로 진행되고 있었지만, 일부 지도 UI가 여전히 구형 `expansionProject`만 확인해 개척 중 점선이 사라지는 문제가 있었습니다.

V0.22에서는 지도 렌더링이 **모든 `frontierProjects[]`**를 표시합니다.

- 출발 정착지 → 목표 타일 점선 연결
- 목표 타일 점선 테두리
- 타일 아래쪽에 현재 진행률 bar
- 여러 개척 프로젝트가 동시에 진행되면 전부 표시
- 목표 타일 상세에서 개척 진행률과 출발지 확인 가능

따라서 정착지가 갑자기 생성되는 것처럼 보이던 시각화 문제가 수정됩니다.

## 4. 물류 지도 색상 변경

내부 물류(`INTERNAL_LOGISTICS`) 흐름은 자원 종류와 관계없이 **하늘색~파란색 계열**을 사용합니다.

- 식량 물류: 밝은 하늘색
- 목재 물류: 중간 파랑
- 석재 물류: 진한 파랑
- 자원 전체 표시도 주된 자원의 파란색 계열 사용

교역 지도는 기존 자원별 색 체계를 유지합니다.

즉 물류 지도와 교역 지도를 색만 보고도 더 쉽게 구분할 수 있습니다.

## 5. V0.21 기반 시스템 유지

다음 V0.21 보강 사항은 그대로 유지됩니다.

- 실제 Person Pioneer
- 지역 정착지들이 실제 잉여 성인을 모아 개척대 구성

- 프런티어 주민 인덱스 재사용

### Devlog

## 6. V0.22 개발 회귀 테스트

### 19×19 30년 인구동학 스모크 테스트

고정 난수 개발용 자연맵 30년 대표 실행에서 대략:

- 최종 인구: **약 149명**
- 누적 출생: **약 233명**
- 질병·쇠약 사망: **약 140명**
- 아사: **약 36명**

으로 나타났습니다.

이 값은 밸런스 목표 자체가 아니라, V0.21의 `적은 출생 + 적은 사망`보다 **출생·사망 turnover가 크게 증가했는지 확인하기 위한 회귀값**입니다.

### 생존 기술 효과 실험

동일 난수 19×19 10년 실험에서 물류·보건 관련 기술을 처음부터 가진 실험군은 대표 실행 기준:

- 일반 상태: 아사 **10**, 질병사 **38**, 최종 인구 **154**
- 생존기술 보유: 아사 **3**, 질병사 **32**, 최종 인구 **162**

으로 나타났습니다.

즉 출생 수가 크게 달라지지 않아도 생존 기술이 사망을 줄여 순인구 증가를 높이는 방향을 확인했습니다.

### 장거리 접촉

100×100 개발용 자연맵에서 초기에는 먼 국가가 대부분 미발견/교역불가 상태를 유지하지만, `BARTER + CART + MARKET + ENVOYS + ROADS + LONG_DISTANCE_TRADE` 등을 갖추면 **거리 약 30~40타일대 일부 국가쌍부터 발견·시장접촉·실제 교역이 열리는 것**을 확인했습니다.

전 세계가 즉시 하나의 시장이 되는 방식은 아닙니다.

### 저장 호환

다음 로드를 확인했습니다.

- V0.20 → V0.22
- 초기 V0.21 → V0.22
- 최종 V0.21 보강판 → V0.22
- V0.22 저장 → V0.22 재로드

기존 인구와 영토가 보존된 상태에서 추가 진행이 가능합니다.
