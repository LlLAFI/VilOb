# Village Observer V0.25

Village Observer는 실제 주민(Person)의 생활과 선택이 **Settlement → Nation → World** 변화로 이어지는 bottom-up 자율 사회 시뮬레이션입니다.

V0.25는 V0.24 장기주행에서 확인된 인구 정체·소국 붕괴·과도한 질병사와, 기존 유지보수/건설 노동의 추상적인 단위를 함께 개편하는 **인구·노동·건물 안정화 패치**입니다. 원래 다음 단계로 계획했던 철/자원 일반화보다 인구와 노동 기반을 먼저 안정화했습니다.

## 1. 질병사 재조정

연령별 기본 연간 질병사 확률을 다음처럼 조정했습니다.

| 연령 | V0.24 | V0.25 |
|---|---:|---:|
| 0~1세 | 14% | **10%** |
| 2~5세 | 7% | **4%** |
| 6~14세 | 2.4% | **1%** |
| 15~59세 | 1.2% | **0.5%** |
| 60~68세 | 2.1% | **1.2%** |
| 69세+ | 3.2% | **3.0%** |

과밀 페널티는 75% 점유율부터 시작하며 계수를 **0.55 → 0.40**으로 낮췄습니다.

건강 상태에 따른 질병 페널티는 Health 60 미만이 아니라 **Health 30 미만**부터 적용됩니다. Health 1 부족당 1.2% 증가 계수는 유지합니다.

현지 식량 비축일이 짧다는 이유만으로 질병 위험이 직접 증가하던 규칙은 삭제했습니다. 이제 식량 부족은 Hunger 증가와 Health 악화를 거쳐 간접적으로 질병 취약성을 높입니다.

질병 관련 기술 효과의 계산은 기존 곱연산을 유지합니다.

- 공공사업: 질병 사망 위험 -10%
- 공중위생: 질병 사망 위험 -48%
- 교육제도: 질병 사망 위험 -8%
- 도시화: 질병 사망 위험 -10%

기존에 숨겨져 있거나 설명과 실제 코드가 달랐던 효과는 기술 설명에 명시합니다.

## 2. Hunger 기반 아사

기존의 `현지 식량비축일 + Hunger 구간별 확률` 방식 아사 판정을 제거했습니다.

새 규칙은 단순합니다.

- 음식을 먹지 못하면 기존 대사 시스템에 따라 Hunger가 증가합니다.
- 높은 Hunger는 기존처럼 Health를 악화시킵니다.
- **Hunger가 100에 도달하면 현재 Health와 무관하게 즉시 아사합니다.**

따라서 `DEATH_STARVATION`은 이제 실제 Person의 Hunger 100 도달을 의미합니다.

Hunger 상승·식사 회복·Health 감소 수치는 이번 버전에서는 기존 값을 유지하고, 다음 장기주행 로그를 보고 다시 조정합니다.

## 3. 개척 거점 수용력

개척 거점(outpost) 수용력을 **2명 → 3명**으로 변경했습니다.

V0.24에서는 3명의 실제 Pioneer가 새 정착지에 도착할 수 있는데도 outpost capacity가 2라 즉시 과밀 페널티를 받는 경우가 있었습니다. V0.25에서는 3인 개척대가 기본 거점에 정상적으로 수용됩니다.

## 4. 건설: 고정 공사기간 → 총 필요 노동량

건설의 핵심 단위를 변경했습니다.

> **노동량 1 = 일반 성인 1명이 하루 동안 건설에 전념했을 때의 작업량**

건물은 더 이상 고정된 `duration`만으로 완공되지 않습니다. 실제 Person이 건설에 배정되어 노동량을 공급해야 합니다.

| 주택 | 430 |

| 곡물창고 | 520 |
| 개척 거점 | 520 |
| 창고/저장고 | 635 |

건설에 배정된 Person은 해당 작업 사이클 동안 본업 생산을 포기합니다. 건축가는 기본적으로 더 높은 유효 건설 노동을 제공하며, 건축 skill도 건설 효율에 반영됩니다.

기존 공공사업의 신규 건설 기간 감소 효과는 동일한 의미를 유지하도록 **필요 건설 노동량 감소**로 해석합니다.

## 5. 유지보수 노동 단위 통합

분기별 기본 유지보수 노동량은 다음과 같습니다.

> **건물 총 건설 노동량 × 0.5% / 분기**

예시:

- 주택 430 → 2.15 노동일/분기
- 개척 거점 520 → 2.60 노동일/분기
- 창고 635 → 3.175 노동일/분기
- 시장 865 → 4.325 노동일/분기

목재·석재 유지비는 기존처럼 연간 건축비 상당량의 2% 기준을 유지합니다.

모든 건물의 열화계수는 이번 버전에서 **1.0**으로 동일하게 시작합니다. 향후 건물의 구조·역할·시대에 따라 별도 계수를 붙일 수 있도록 확장 가능한 구조를 사용합니다.

## 6. Condition 변화 공식 개편

최종 유지보수 충족률은 노동 충족률과 자재 충족률 중 낮은 값입니다.

충족률의 소수점 아래는 **올림하여 정수 %**로 판정합니다.

- 79.01% → 80%
- 80.01% → 81%
- 99.01% → 100%

분기별 Condition 변화는 다음과 같습니다.

| 유지보수 충족률 | Condition 변화 |
|---:|---:|
| 100% | +10.0 |
| 90~99% | +5.0 ~ +9.9 선형 |
| 81~89% | +1.0 ~ +5.0 선형 |
| 80% | 0 |
| 0~79% | -2.0 ~ 0 선형 |

정확한 구간식:

- `R = 100`: +10
- `90 ≤ R ≤ 99`: `5 + (R-90) × 4.9/9`
- `81 ≤ R ≤ 89`: `1 + (R-81) × 4/8`
- `R = 80`: 0
- `0 ≤ R ≤ 79`: `-2 × (80-R)/80`

완전히 유지보수를 받지 못해도 Condition은 최대 **-2/분기**만 감소합니다. 따라서 Condition 100에서 0까지 완전 방치 기준 약 12.5년이 필요합니다.

Condition 0인 건물도 수리 대상에서 제외되지 않습니다. 누적 수리가 **15**에 도달하면 다시 활성화됩니다.

## 7. Condition 0 이후 폐허화

Condition 0은 즉시 건물 삭제를 의미하지 않습니다.

| 건물 | Condition 0 이후 폐허화 |
|---|---:|

이번 버전부터 기존 `시청` 표기는 **고대 시청**으로 시작합니다. 향후 시대 진행에 따라 중세 시청, 근세 시청 등으로 개축되는 체계를 확장할 예정입니다.

## 8. 새 지역 유지보수 지원망

V0.24의 추상적인 `remoteLabor 0.x` 방식은 폐기하고 **실제 Person의 실제 노동일**을 사용합니다.

기본 흐름:

1. 각 정착지의 건물을 우선순위대로 정렬합니다.
2. 현지 주민이 먼저 유지보수 노동일을 배정받습니다.
3. 부족한 시설은 같은 국가의 다른 정착지에 지원을 요청합니다.
4. 실제 Person이 이동 및 작업 일정에 배정됩니다.
5. 파견 기간 동안 해당 Person은 본업 생산을 포기합니다.
6. 이동 경로비 **1 = 편도 이동 1일**로 계산합니다.

고정된 최대 파견기간은 두지 않습니다. 단, 한 분기의 실제 가용일을 넘어서는 임무는 배정되지 않습니다.

다른 정착지에서 파견할 때는 기본적으로 **최소 성인 1명은 출발 정착지에 남기며**, 식량 상황이 불안하면 마지막 핵심 식량 생산자를 보호합니다.

건물 유지보수 우선순위는 기존 값을 유지합니다.

| 건물 | 우선순위 |
|---|---:|
| 고대 시청 | 100 |
| 주택 | 95 |
| 개척 거점 | 92 |
| 곡물창고 | 82 |
| 경작지 | 80 |
| 창고/저장고 | 78 |
| 목책 | 66 |
| 도로 | 62 |
| 채석장 | 58 |
| 기타 기본 | 50 |
| 교역소 | 45 |
| 시장 | 40 |

원격 파견의 재검토 주기와 파견 가치 판단은 AI 성향별로 다릅니다. 생존안정형은 생활 기반시설에, 영토확장형은 개척거점·도로에, 교역외교형은 교역시설에, 도시형은 도시 핵심시설에, 자원개척형은 생산·자원시설에 상대적으로 높은 가치를 둡니다.

건축가는 현재 유지보수 효율 **×1.20**을 유지합니다. 향후 직업의 시대별 발전에 따라 이 배율을 확장할 수 있습니다.

## 다음 검증 포인트

V0.25 장기주행에서는 특히 다음을 확인합니다.

1. 식량이 안정된 국가가 지속적으로 인구를 늘리는가

3. 질병사가 전체 사망의 압도적 다수를 차지하지 않는가

5. 평균 Hunger가 국가 간 위기 차이를 잘 보여주는가
6. 유지보수 노동 0.5%가 실제 가용 노동에 비해 과도하거나 지나치게 가볍지 않은가
7. 건설 전업으로 인해 생산이 과도하게 무너지지 않는가
8. 원격 유지보수 이동일이 합리적인 비용으로 작동하는가
9. Condition 80% 손익분기점과 느린 열화가 건물 붕괴 빈도를 안정시키는가
10. 개척 거점 capacity 3이 초기 과밀·질병 문제를 완화하는가
