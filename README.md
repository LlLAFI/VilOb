# Village Observer V0.24

Village Observer는 실제 주민(Person)의 생활과 선택이 **Settlement → Nation → World** 변화로 이어지는 bottom-up 자율 사회 시뮬레이션입니다.

V0.24는 V0.23을 약 66년까지 장기 관찰한 결과를 바탕으로 만든 **시간·정착지 성장·시설 유지관리 기반 개편**입니다. V0.23에서 확인된 핵심 문제는 10년 이후 정착지 순증이 지나치게 느려지는 현상, 외곽 정착지가 재료 부족보다 현지 노동력 부족으로 붕괴하는 현상, 사회 탭 범위 선택기가 실행 중 계속 닫히는 UI 회귀였습니다.

V0.24의 핵심은 다음과 같습니다.

1. **360일제: 4분기 × 90일**
2. **실제 출생일·생일·연령 + 연중 분산 출생/사망**
3. **지역 공동 개척 인력과 2차 개척 물결**
4. **인근 정착지 유지보수 노동 지원망**
5. **건축가의 유지보수 전문성 반영**
6. **사회 탭 selector DOM 보존**
7. **장기 로그·성능 부담 억제 및 진단 강화**

철·광산·제련 등 신규 자원경제는 V0.25 이후로 미뤘습니다.

## 1. 360일제와 실제 생일

한 해는 이제 다음처럼 구성됩니다.

- 1년 = **360일**
- 1분기 = 90일
- 총 4분기
- 화면에는 `N년 N분기 N일`로 표시

기존 V0.23까지의 경제·생산·물류 밸런스를 갑자기 3배로 바꾸지 않기 위해 기존 경제 시뮬레이션의 120회/년 작업주기는 유지합니다. 즉 **달력은 매일 흐르지만 주요 경제 작업주기는 3일마다 한 번** 실행됩니다.

각 Person은 다음 값을 가집니다.

- 실제 출생 ordinal
- 출생 연도
- 출생 분기
- 출생일
- 현재 날짜에 따른 실제 나이

초기 주민은 시작 시점의 나이에서 역산한 과거 출생일을 받습니다. 출생 연도가 세계 시작 이전일 수도 있습니다.

주민 목록에는 `출생 N년 N분기 N일`이 표시됩니다.

### 연중 분산 인구동학

V0.23까지 연초에 몰려 있던 출생·질병사망·아사·노환 판정을 일일 hazard로 변환했습니다.

- 출생은 연중 여러 날짜에 발생
- 질병·영양실조·노환 사망도 연중 분산
- 생일이 지나야 나이가 증가
- 기존 연간 확률의 규모는 360일 일일 확률로 환산해 최대한 보존

기술에 따른 질병·아사 감소 효과도 계속 적용됩니다.

## 2. 지역 공동 개척과 2차 개척 물결

V0.23 장기 테스트에서는 초반 약 10년 동안 정착지가 빠르게 늘어난 뒤, 작은 외곽 정착지가 자체적으로 충분한 성인을 확보하지 못해 20~60년 구간의 확장이 거의 멈췄습니다.

V0.24는 9년차 이후 **Regional Pioneer Pool**을 사용합니다.

- 실제 Person만 개척민이 될 수 있음
- 개척 출발지는 실제 정착지여야 함
- 출발지 한 곳의 성인만 보는 대신 주변 정착권의 성인을 함께 탐색
- 중심지는 최소한의 성인 인구를 보존
- 외곽 정착지는 혼자 살아 있는 마지막 주민까지 빼가지는 않음
- 주변에 다른 주민이 남아 있다면 외곽의 유휴 성인을 공동 개척에 참여시킬 수 있음
- 도로·개척 보급술은 지역 인력권과 동시 개척 능력을 강화
- 인접·매립형 확장을 강하게 선호해 촉수형 영토 확장을 억제
- 실제 Pioneer가 출발하고 완료 시 실제로 새 정착지에 이동

국가 인구, 기술, 성향에 따라 병렬 개척 가능 수가 점진적으로 증가합니다.

### V0.24 고정난수 25년 회귀 결과

개발용 seed 24680에서:

| 시점 | 세계 인구 | 정착지 |
|---|---:|---:|
| 5년 | 115 | 22 |
| 10년 | 132 | 48 |
| 15년 | 138 | 61 |
| 20년 | 152 | 76 |
| 25년 | 143 | 87 |

25년 동안 개척 시작 91회, 영토 확보 85회, 전초기지 폐허화 5회가 발생했고 6개 국가가 모두 생존했습니다.

이 값은 고정 밸런스 보장이 아니라 **V0.23에서 사라졌던 10년 이후의 2차 개척 물결이 실제로 생기는지 확인하기 위한 회귀값**입니다.

## 3. 지역 유지보수 지원망

V0.23 장기 로그에서는 비활성 건물 대부분이 목재·석재 부족이 아니라 다음 패턴으로 발생했습니다.

- `laborRatio = 0`
- `resourceRatio = 1`

즉 재료는 있는데 해당 타일에 성인 노동자가 없어 건물이 열화되는 경우가 많았습니다.

V0.24에서는 유지보수 노동이 다음 순서로 공급됩니다.

1. 현지 성인·청소년 노동
2. 같은 국가의 가까운 정착지에서 실제 성인 지원
3. 그래도 부족하면 기존처럼 건물 상태 하락

주변 노동자는 실제 Person이며 지원 시 `workTileId`가 대상 정착지로 바뀌고 유지보수 행동 상태를 갖습니다.

지원 가능 범위는 경로비를 사용하며 도로 기술이 있으면 더 넓어집니다.

### 전초기지 규칙

전초기지의 기존 폐허 규칙은 유지했습니다.

- 관리되지 않는 전초기지는 계속 열화
- 상태 0에서 장기간 방치되면 붕괴
- 외곽 정착지가 유지 불가능하면 영토 후퇴 가능

즉 정착지를 무조건 보존하는 패치가 아니라 **근처에 실제 지원 인력이 있는데도 현지 성인이 없다는 이유만으로 붕괴하는 현상**을 완화합니다.

## 4. 건축가 전문화의 시작

기존 직업 `건축가`를 유지보수 시스템에 연결했습니다.

V0.24에서는 건축가가 필수 조건은 아닙니다. 고전시대의 단순 주택·농업시설·전초기지는 일반 성인도 보수할 수 있습니다.

다만 건축가는:

- 원격 유지보수 노동 효율 증가
- 유지보수에 참여하면 전체 유효 노동력 보너스
- 기존 건설 프로젝트의 작업 효율 역할 유지

를 가집니다.

이는 향후 석조 대형건물, 집합주택, 공장, 철도처럼 **전문 기술 인력이 없으면 정상 유지가 어려운 시설**로 확장하기 위한 첫 단계입니다.

---

## 5. 사회 탭 selector 버그 수정

V0.23에서는 국가 `사회` 탭의 범위 selector가 약 550ms마다 DOM 전체와 함께 재생성되어, 사용자가 메뉴를 열면 실행 중 계속 닫히는 문제가 있었습니다.

V0.24에서는:

- selector DOM을 그대로 보존
- 국가/영토 목록이 실제로 바뀔 때만 option 구조 갱신
- 인구통계 body만 매 render 갱신
- selector에 포커스가 있을 때 값을 강제로 다시 쓰지 않음

으로 수정했습니다.

범위는 계속 다음 세 가지를 지원합니다.

- 세계
- 현재 국가
- 개별 정착지

## 6. 생존기술 연구 AI 보정

V0.23의 장기 주행에서 `SANITATION`, `PUBLIC_WORKS` 계통은 자연스럽게 등장하기는 했지만 너무 늦었습니다.

V0.24는 기술을 무료로 지급하거나 전체 연구속도를 크게 높이지 않고, 최근 8년의:

- 아동 사망률
- 질병사망 압력
- 아사 압력

이 높을 경우 `SANITATION / PUBLIC_WORKS / FOOD_PRESERVATION`뿐 아니라 **그 선행기술 경로 전체의 연구 가중치**를 더 강하게 올립니다.

## 7. Gold 및 개발자 진단

V0.23에서 확인된 국가 간 Gold 편중은 V0.24에서 본격적인 경제 재설계를 하지 않습니다.

대신 snapshot에 다음 진단값을 추가합니다.

- 세계 Gold Gini
- 최대 국가 Gold 점유율
- 국가별 누적 교역 순 Gold

향후 국제경제 개편의 기준 데이터로 사용합니다.

---

## 8. 성능과 로그 정책

V0.23 60년대 장기 테스트에서 약 `SIM 50ms / UI 2ms` 수준까지 증가했지만 실제 플레이 체감은 약간의 렉이 있는 정도로 사용 가능한 상태였습니다.

V0.24는 360일제를 도입하면서 연간 핵심 경제 연산 횟수를 기존과 동일한 120회로 유지하여 달력 변경만으로 계산량이 3배가 되지 않도록 했습니다.

또한 원격 유지보수 telemetry는 타일마다 별도 이벤트를 남기지 않고 **국가·분기별 `MAINTENANCE_SUPPORT_SUMMARY`**로 묶어 장기 로그 증가를 억제합니다.

상세 routine event 보존창은 실제 정책과 일치하도록 **30년**으로 기록합니다.

성능 최적화는 계속 진행 중이며 100×100 지도에서는 별도의 추가 최적화가 필요합니다.

## 9. 저장 및 호환성

V0.24 저장 버전:

- `version: 0.24`
- localStorage key: `village-observer-v0-24`

V0.23 이하 기존 저장을 불러올 때 기존 호환 체인을 거친 뒤 V0.24 상태를 부착합니다.

V0.23 → V0.24 호환 회귀에서:

- 인구 보존
- Gold 보존
- 기존 접촉망 보존
- V0.24 실제 출생일 생성
- V0.24 재저장/재로드 정상

을 확인했습니다.

개발 로그와 CSV 파일명도 `v024`를 사용합니다.

## 10. V0.24 회귀 테스트

확인한 항목:

- HTML 내부 31개 script `node --check` 통과
- 새 세계 V0.24 정상 생성
- 1년 1분기 90일 → 1년 2분기 1일 경계 정상
- 360일 경과 시 Person 실제 나이 +1
- 출생이 여러 분기와 날짜로 분산
- 사회 탭 selector가 render 후에도 동일 DOM node로 유지
- V0.23 세이브 → V0.24 로드 및 V0.24 round-trip 정상
- 고정난수 25년 브라우저 자동주행에서 6개 국가 생존, runtime error 없음
- 20년 76개 / 25년 87개 정착지로 중기 확장 지속 확인
- 유지보수 지원망 telemetry 정상 누적

30년 이상의 자동 개발 스트레스런은 실행 환경 제한 때문에 완주시키지 못했으므로, 실제 장기 밸런스는 V0.24 플레이 로그에서 다시 확인해야 합니다.
