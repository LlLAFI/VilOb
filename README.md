# Village Observer V0.20

Village Observer는 실제 주민(Person)의 생활과 선택이 정착지(Settlement), 국가(Nation), 세계(World)의 변화로 이어지는 **bottom-up 자율 사회 시뮬레이션**입니다.

V0.20은 V0.19의 지역시장·6국가·상업/석재 전문화 기반 위에서, 앞으로의 **100×100 대형 지도, 산업 자원, 군사·전쟁 시스템**까지 확장하기 위한 **인구·노동·공간 성장 기반 패치**입니다.

이번 버전의 핵심은 국가 하나가 모든 개척과 노동을 직렬로 처리하던 구조를 완화하고, 실제 정착지와 실제 Person이 더 직접적으로 공간 성장과 전문 생산을 담당하도록 바꾸는 것입니다.

---

## V0.20 핵심 변경사항

### 1. 정착지 기반 병렬 개척

기존에는 국가마다 사실상 하나의 `expansionProject`만 진행할 수 있어, 국가가 커져도 영토 확장 속도가 거의 가속되지 않았습니다.

V0.20에서는 실제 주민이 있는 여러 정착지가 조건을 만족하면 **서로 다른 변경에서 동시에 개척대를 보낼 수 있습니다.**

- 개척은 실제 성인 주민 2명을 Pioneer로 사용
- 출발 정착지의 주민 수와 식량 사정을 확인
- 국가 전체 식량·목재·석재·Gold도 필요
- 개척 중인 출발 정착지는 같은 시점에 또 다른 개척대를 보내지 않음
- 이미 다른 개척 프로젝트가 목표로 삼은 타일은 중복 예약하지 않음
- 개척 성공 시 Pioneer 한 명이 실제로 새 정착지에 남음
- 개척 실패·경쟁 선점·보급 붕괴도 기존처럼 기록

동시 개척 한도는 국가의 **인구와 실제 유인 정착지 수**가 커질수록 단계적으로 증가합니다. 영토확장형은 같은 조건에서 한 슬롯을 더 확보할 수 있고, 도시집약형은 다소 보수적입니다.

따라서 앞으로 큰 지도에서도 `국가 크기 증가 → 변경 정착지 증가 → 개척 가능 주체 증가 → 공간 팽창 가속`이 자연스럽게 일어날 기반을 마련했습니다.

### 2. 거주지와 직장 분리

Person에 다음 두 위치 개념을 분리했습니다.

- `homeTileId`: 거주 정착지
- `workTileId`: 실제 일하는 정착지

기존 저장 파일의 주민은 불러올 때 기본적으로 거주지와 직장이 같은 것으로 마이그레이션됩니다.

현재 통근은 **추상화된 접근 비용**으로 처리하며, 하루 단위 이동 애니메이션이나 실제 이동시간은 아직 구현하지 않았습니다. 하지만 주민은 가까운 다른 정착지의 적절한 일자리로 출근할 수 있습니다.

이 구조는 향후 광산·제련소·공장·군부대 등 전문 시설의 실제 고용 기반으로 확장할 수 있습니다.

### 3. 전문 채석장의 실제 고용 슬롯

V0.19에서는 전문 채석장이 있어도 그 타일에 우연히 광부가 살지 않으면 생산이 끊길 수 있었습니다.

V0.20에서는 채석시설을 실제 일자리로 취급합니다.

- 일반 채석장: 광부 슬롯 2명
- 전문 채석장: 광부 슬롯 5명
- 주변 성인은 현지 석재 가치, 남은 자연 석재, 빈 일자리, 접근비용 등을 보고 광부 직업/근무지를 선택
- 자원개척형 국가는 석재 생산 일자리에 조금 더 적극적
- 한 번 배치된 광부는 일정 기간 직장 배치를 유지해 지나친 일일 직업 흔들림을 방지

실제 채굴도 `homeTileId`가 아니라 `workTileId`의 자연자원을 사용합니다.

### 4. 석재 가공장 과잉건설 억제

V0.19에서는 높은 석재 가격만으로 석재 가공장이 과도하게 지어질 수 있었습니다.

V0.20에서는 석재 가공장에 **실제 상류 공급과 실제 건설수요**가 필요합니다.

- 최근 건설 활동이 충분해야 함
- 인근에 사용 가능한 채석장/전문 채석장이 있거나 최근 실질적인 석재 수입이 있어야 함
- 국가 내 가공장 수가 채석 인프라 규모에 비해 지나치게 많으면 추가 건설을 제한

따라서 의도한 흐름은 다음과 같습니다.

`석재 매장 → 채석시설 → 실제 광부 고용 → 생산/수입 → 가공 → 건설`

석재 가공장은 여전히 현지 건설의 석재 효율을 높이지만, 가격 상승 자체만으로 자동 증식하지 않습니다.

### 5. 좋은 생활환경에서의 완만한 인구성장 가속

장기적으로 실제 Person 기반 도시·산업·군사 시스템을 운용하려면 현재보다 더 큰 인구가 필요합니다. 다만 출산율을 일괄 배수로 올리지는 않았습니다.

다음 조건이 충분히 좋은 국가에서만 기존 출산 이후 **작은 추가 출산 기회**가 생깁니다.

- 충분한 식량 비축
- 인구보다 여유 있는 주거능력
- 양호한 평균 건강
- 양호한 평균 행복
- 해당 정착지의 최소 식량 여유
- 실제 가임 연령 부모 존재

추가 출산에도 기존 산모 출산 쿨다운을 적용합니다. 따라서 풍요롭고 안정된 사회는 인구가 조금 더 빠르게 증가하지만, 식량난·주택난·건강 악화 상태에서 인구만 강제로 증가하지 않습니다.

### 6. 국가 → 사회 탭

실제 주민 구조를 직접 관찰할 수 있도록 국가 화면에 **사회** 탭을 추가했습니다.

국가 전체 또는 개별 정착지를 선택해 다음을 볼 수 있습니다.

- 10세 단위 **인구 피라미드**
- 남성/여성 **성비 도넛 차트**
- **직업 분포** 가로 막대그래프
- 다른 정착지로 출근하는 통근자 수
- 광부 수

이 화면은 앞으로 출산 밸런스, 산업 노동력, 전쟁 동원 가능 인구 등을 관찰하는 기반으로 사용합니다.

### 7. 주민 화면에 거주지/근무지 표시

주민이 다른 정착지로 출근하는 경우 주민 정보에서 **거주 정착지와 근무 정착지**를 함께 확인할 수 있습니다.

국가 개요에서도 현재 동시 개척 프로젝트 수와 통근자 수를 확인할 수 있습니다.

### 8. 통계 선택창 깜빡임 수정

게임 자동 진행 중 세계/국가/정착지 통계의 `식량`, `목재`, `석재` 같은 지표 선택창을 열면 틱마다 `<select>` 자체가 재생성되어 깜빡이거나 닫히는 문제가 있었습니다.

V0.20에서는:

- 선택 가능한 항목 구성이 실제로 바뀔 때만 option 목록을 재구성
- 일반 시뮬레이션 틱에서는 그래프와 값만 갱신

하도록 변경했습니다.

이는 향후 100×100 지도에서 전체 UI를 매 틱 재생성하는 비용을 줄여 나가기 위한 첫 단계이기도 합니다.

## V0.19 기능 유지

다음 V0.19 기능은 그대로 유지됩니다.

- 6개 국가 / 6개 AI 성향
  - 생존안정형
  - 교역외교형
  - 영토확장형
  - 균형형
  - 도시집약형
  - 자원개척형
- MapData A~F 6 Spawn 지원
- 구형 4~5 Spawn 지도 자동 보완
- 정착지별 지역가격과 제한된 시장정보
- 식량 긴급수입 / 국내물류 우선
- 상단 회관·대시장 상업 전문화
- 채석장→전문 채석장
- 석재 가공장
- 건축공간·토지개발·주거 세대교체
- Gold 기반 축제
- 실제 생산량 30일/120일 통계
- 물류·교역 방향 흐름 지도와 필터
- 국가/지도 6색 아이덴티티 통일

## 개발자 로그 / CSV

V0.20 스냅샷에는 기존 V0.19 진단값에 다음 값이 추가됩니다.

- `frontierProjects`: 현재 진행 중인 병렬 개척 프로젝트 수
- `frontierProjectCap`: 현재 국가의 동시 개척 한도
- `commuters`: 거주지와 근무지가 다른 살아있는 주민 수
- `quarryWorkerSlots`: 현재 채석시설이 제공하는 광부 슬롯 수
- `quarryWorkers`: 실제 채석시설에 배치된 광부 수

JSON `worldSummary`에도 다음 모델 활성 상태가 기록됩니다.

- population structure observer UI
- home/workplace separation
- settlement-led parallel frontier expansion
- quarry employment / stone continuity
- stable statistics controls

기존 최근 상세 이벤트 + 연간 요약 구조는 이번 버전에서는 그대로 유지합니다.

## 저장 호환성

- 현재 저장 버전: **0.20**
- localStorage 키: `village-observer-v0-20`
- **V0.8 ~ V0.20** 저장 파일 불러오기 지원
- V0.19 이하 저장의 Person은 `workTileId = homeTileId`로 안전하게 초기화
- 기존 단일 개척 프로젝트가 남은 저장은 V0.20의 병렬 frontier 프로젝트 형식으로 마이그레이션
- MapData v1 및 A~F 6 Spawn 지원 유지

## 현재 의도적으로 보류한 장기 기능

이번 패치는 향후 시스템의 기반만 마련하며 다음은 아직 구현하지 않았습니다.

- 철·보크사이트·알루미늄·우라늄 등 추가 산업자원
- 원광→제련→제품의 완전한 생산체인
- 실제 통근 이동시간/교통혼잡
- 군사 직업, 장비, 계급, 부대, 전쟁과 점령
- AI 정책의 머신러닝/Q-learning
- 200~300년 테스트를 위한 개발자 로그 계층화·압축
- 100×100 기본 지도 전환

장기적으로는 **고정된 AI 성격/핵심 가치 + 경험을 통해 조정되는 정책**, 실제 Person 군인과 산업 노동자, 데이터 기반 자원 레지스트리로 확장하는 방향을 전제로 합니다.
