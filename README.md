# Village Observer V0.32D1

**릴리스명:** D 안정화 · 야전 Formation 실분리와 관측 버그 수정  
**버전:** 0.32D1  
**기준 버전:** V0.32D  
**세이브 키:** `village-observer-v0-32d1`

V0.32D1은 V0.32D의 신규 기능을 확장하는 버전이라기보다, 122년 장기 자연주행에서 확인된 **“화면에는 보이지만 실제 행동 계층에서는 충분히 발화하지 않는 문제”**를 정리하는 안정화 패치다. 전투·점령·포로·전사 처리는 아직 추가하지 않는다. 이번 패치의 핵심은 D에서 약속했던 야전 Formation, 행정청, 통계 그래프, 지도 표시 모드가 실제 시뮬레이션과 관측 화면에서 일관되게 작동하도록 만드는 것이다.

## 1. 핵심 변경 요약

### 1.1 Garrison과 야전 Formation의 실제 분리

V0.32D에서는 기존 V0.32B의 핵심 Garrison Cohort를 Formation으로 감싸는 성격이 강해, 장기 자연주행에서 Formation 객체와 지도 마커는 존재했지만 실제 이동 누적이 0으로 유지될 수 있었다.

D1에서는 실제 현역 Person을 두 집단으로 분리한다.

- **Garrison Cohort**: 수도에 고정되는 방어 병력
- **Field Cohort**: 지도 위에서 이동하는 야전 병력
- **Formation**: Field Cohort만 참조하는 지도상의 기동 단위

현역이 2명 이상이면 최소 1명은 Garrison에 남고, 약 45%를 목표로 Field Cohort를 편성한다. 한 Person ID가 Garrison과 Field Cohort에 동시에 들어가지 않도록 매 동기화 때 실제 현역 명단을 다시 분할한다.

야전 Formation은 자국 영토 안에서 다음 요소를 평가한다.

- 외국과 접한 국경
- 행정 중심지
- 철광산·제련소·대장간 등 전략 산업
- 군사시설
- 도로
- 인구가 많은 거점
- 개척 전선
- 국가 군사 교리와 전략 경계도

충분한 자국 영토가 있으면 수도가 아닌 전략 타일을 우선 후보로 삼는다. 이동은 개별 병사의 pathfinding이 아니라 Formation 단위의 타일 이동으로 처리한다.

**중요:** Formation의 병력은 여전히 실제 `Person` ID의 집합이다. 가상 병력을 생성하지 않는다.

### 1.2 군사 지도 표시

군사 레이어에서 병력 역할을 구분한다.

- `■N`: 수도에 고정된 Garrison
- `▲N`: 이동 가능한 Field Formation

둘 모두 실제 현역 Person 수를 표시한다. 전투는 아직 비활성 상태다.

### 1.3 Formation 이동 계수 수정

V0.32D에서는 같은 분기 안에서 이동 로그를 집계하는 과정에서 실제 이동이 있었더라도 누적 이동 수가 정확히 증가하지 않을 수 있었다. D1에서는 **실제 타일 이동마다 `formationMoves32D`가 증가**하며, 로그 집계 여부와 이동 카운터가 분리된다.

## 2. 통계 탭 수정

### 2.1 세계 직접 지표 그래프 복구

V0.32D의 세계 통계는 이미 연간 `global` 행을 선택한 뒤 다시 `row.global`을 찾는 이중 참조 오류가 있었다. 그 결과 다음 지표에서 유효한 값이 없어 그래프가 비어 있었다.

- 세계 인구
- 세계 영토 타일
- 세계 국가 평균 기술 수
- 세계 행정 중심지 수

D1에서는 연간 세계 행을 직접 읽도록 수정했다.

### 2.2 D 통계 그룹 구조 유지

D에서 도입한 한국어 그룹형 통계 구조는 유지한다.

- **생활 상태**: 평균 건강 / 평균 허기 / 평균 행복
- **지식**: 누적 지식 / 국가별 평균 지식 / 1인당 지식
- **골드**: 전체 통화량 / 국가 금고 골드 / 정착지 시장 골드 / 개인 보유 골드
- 자원 보유량 및 평균 가격: 자원 드롭다운 방식

골드 생성·소멸 audit은 내부 검증용 telemetry로 유지하지만 일반 통계 선택지에는 노출하지 않는다.

## 3. 지도 표시 모드 수정

V0.32D의 `국가 중심 / 균형 / 지형 중심` 선택기는 상태값은 변경했지만 실제 최종 활성 지도 renderer가 고정된 영토 tint를 사용하여 화면 변화가 보이지 않을 수 있었다.

D1에서는 최종 활성 렌더 경로가 `mapTerritoryStyle32D`를 직접 사용하도록 정리했다.

- **국가 중심:** 국가 tint 약 40%
- **균형:** 국가 tint 약 30%
- **지형 중심:** 국가 tint 약 9%
- 국가 간 검은 국경선은 모든 모드에서 유지

따라서 지형 중심에서는 숲·평야·암석·산악 등 원래 지형색이 훨씬 강하게 보인다.

## 4. 행정권과 고대 행정청 안정화

### 4.1 A/B/C 행정권 연속성

행정 중심지는 인구·도시성·상업성·거리 변화에 따라 인접 Settlement로 조금씩 이동할 수 있다. D에서는 중심 타일 ID가 바뀌면 같은 지역이어도 새 행정권으로 취급되어 6년 안정 카운터가 초기화될 가능성이 있었다.

D1에서는 다음 조건에서 기존 행정권 정체성을 승계한다.

- 기존 비수도 행정 중심지가 최근 720일 이내 존재했음
- 새 행정 중심지가 기존 중심에서 지도 거리 3 이내
- 이미 다른 현재 행정 중심지가 해당 코드를 사용하지 않음

이 경우 A/B/C 코드와 `activeSince`를 새 중심지로 넘긴다. 수도권 A는 계속 고정이다.

### 4.2 고대 행정청 건설

비수도 행정 중심지가 **연속 6년** 유지되면 고대 행정청을 전략 건설 대상으로 삼는다.

기본 조건:

- 국가가 활성 상태
- `ADMINISTRATION` 기술 보유
- Survival Mode 아님
- 식량 비축 30일 이상
- 비수도 행정 중심지가 6년 이상 안정
- 해당 위치에 행정청이 없고 공사 중도 아님
- 공사 슬롯과 재료 확보 가능

고대 행정청:

- 목재 34
- 석재 22
- 골드 0
- 건축공간 1.8
- 총 노동량 **900 adult-day**

공간이 부족하지만 개발 잠재 공간이 남아 있으면 행정청을 포기하지 않고 해당 중심지의 토지 정비를 먼저 시도한다.

### 4.3 행정청 진단 추가

국가 경제 화면과 telemetry에서 다음 값을 확인할 수 있다.

- 행정청 목표 타일
- 해당 중심지 안정 연수
- 공간정비 시도 횟수
- 현재 차단 사유

대표 차단 사유:

- `TECH`
- `SURVIVAL_MODE`
- `FOOD_RESERVE`
- `NO_STABLE_CENTER`
- `SPACE_PREP`
- `SPACE`
- `PROJECT_CAPACITY`
- `MATERIALS_OR_GATE`
- `PENDING`
- `ALREADY_BUILT`
- `NONE`

이를 통해 장기주행에서 행정청이 나타나지 않을 경우 원인을 Devlog에서 직접 추적할 수 있다.

## 5. 초기 가격 안정화

D에서는 시작 기준가격 자체만 변경했기 때문에 적응형 가격 계산이 곧바로 값을 덮어쓸 수 있었다. D1에서는 신규 세계의 기준가격을 초기 안정화 구간에 실제로 유지한다.

- 목재: **0.35**
- 석재: **0.49**
- 철광석: **0.90**

동작 방식:

1. 1년 차: 위 기준가격을 유지
2. 2~3년 차: 기준가격과 실제 수요·공급 기반 적응가격을 점진적으로 혼합
3. 3년 이후: 기존 적응형 가격 시스템으로 완전히 전환

식량·철·도구 등 나머지 자원 가격 규칙은 변경하지 않는다.

## 6. Devlog 압축 2차

V0.32D에서 오래된 상세 이벤트를 연간 `LOG_SUMMARY32D`로 압축했지만, 120년대에도 최근 5년의 고빈도 로그가 큰 용량을 차지했다.

D1의 보존 기간은 이벤트 유형별로 더 짧게 조정한다.

- `INTERNAL_LOGISTICS`: 최근 **2년** 상세 유지
- `TREASURY_RESERVE_BLOCK`: 최근 **2년** 상세 유지
- 군사 전략 슬롯 차단 상세: 최근 **2년** 유지
- `V28_FOOD_ACCESS_BLOCKED`: 최근 **3년** 상세 유지
- `EMERGENCY_FOOD_CONVOY`: 최근 **3년** 상세 유지
- 그보다 오래된 기록: 연도·국가·자원/원인 단위 `LOG_SUMMARY32D`로 집계

집계 로그에는 이벤트 수, 이동량, 이동 횟수, 최대 평균 Hunger, 심각 Hunger 관측, 영향 타일 수, 골드 비용 합계 등을 가능한 범위에서 보존한다.

Formation 이동은 분기별 상세 집계 방식을 유지하면서, 누적 이동 칸 수는 별도로 정확하게 기록한다.

## 9. 세이브 호환성

D1 저장 버전은 `0.32D1`이다.

## 11. 아직 포함하지 않은 것

V0.32D1은 전투 버전이 아니다. 다음 기능은 의도적으로 포함하지 않는다.

- 국가 간 전투 판정
- 전사·부상·포로
- 적 영토 침공/점령
- 공성전
- 임시 야전 요새
- 평화협정 및 영토 양도

이 기능들은 Formation의 자연 이동과 장기 안정성이 확인된 뒤 후속 V0.32E/F 단계에서 추가하는 것이 목표다.
