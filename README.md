# Village Observer V0.16

Village Observer는 실제 주민(Person)의 생활과 선택이 정착지(Settlement), 국가(Nation), 세계(World)의 변화로 이어지는 **bottom-up 자율 사회 시뮬레이션**입니다.

V0.16은 V0.15의 152년 장기 관찰에서 확인된 **후반 AI 실행 고착, 전략 자원 조달 부족, 건물 재활성 진동, 장기 변화 관찰의 어려움**을 보완하고, 기본 자연 세계를 19×19로 확장한 버전입니다. 기술 트리의 연구 속도와 기존 36개 기술 구조는 이번 버전에서 변경하지 않았습니다.


## V0.16 핵심 변경사항

### 1. 기본 자연 생성 세계 19×19
기본 새 세계 크기를 기존 **14×14(196타일)**에서 **19×19(361타일)**로 확장했습니다. 기본 국가는 이전과 동일하게 4개로 유지해, 맵 크기 변화가 장기 성장과 접경 형성에 주는 영향을 따로 관찰할 수 있도록 했습니다.

MapData로 불러오는 사용자 제작 지도는 기존처럼 자체 width/height를 그대로 사용합니다. 이번 확장은 향후 100×100 이상의 대형 실제 지형형 지도 실험을 위한 중간 단계입니다.

### 2. 지도에서 국가·정착지로 바로 이동
소유자가 있는 지도 타일을 선택하면 타일 정보 아래에 다음 버튼이 나타납니다.

- **이 정착지 보기**: 해당 국가의 `정착지` 탭으로 이동하고 선택한 타일의 정착지 카드를 강조합니다.
- **국가 개요 보기**: 해당 소유 국가의 `개요` 탭으로 바로 이동합니다.

지도에서 발견한 현상을 국가 화면에서 다시 찾는 과정을 줄였습니다.

### 3. 통계 탭과 장기 그래프
하단 메뉴에 **📊 통계** 탭을 추가했습니다. 연간 기록을 이용해 시간에 따른 변화를 선 그래프로 확인할 수 있습니다.

대상은 `세계 / 국가 / 정착지`, 기간은 `전체 / 최근 10년 / 최근 25년 / 최근 50년`을 선택할 수 있습니다.

- 세계: 인구, 식량, 목재, 석재, Gold, 영토, 평균 건강·행복, Knowledge
- 국가: 인구, 식량, 목재, 석재, Gold, 영토, 평균 건강·행복, 기술 수, Knowledge
- 정착지: 인구, 식량, 목재, 석재, 건물 평균 상태

정착지는 현재 별도 Gold 지갑을 갖지 않기 때문에 정착지 Gold 그래프는 제공하지 않습니다. 새 V0.16 세계부터 정착지별 연간 히스토리가 세이브에 함께 저장됩니다.

### 4. AI 실행 가능성 검사와 차선 행동
계절 AI가 가장 높은 점수의 행동을 고르더라도 실제로 실행할 수 없는 경우가 반복되는 문제를 완화했습니다.

`HOUSING / SECURITY / EXPAND` 선택 전에 공사 슬롯, 건설 가능한 타일, 인구·개척자 조건, 식량 비축, 목재·석재·Gold 비용을 검사합니다. 1순위 행동이 실행 불가능하면 같은 점수표에서 다음으로 높은 **실행 가능한 행동**을 선택합니다.

선택 뒤 실제 실행 단계에서 추가 조건 때문에 실패한 경우에도 한 번 더 차선 행동을 시도합니다. 개발자 로그에는 `AI_ACTION_FALLBACK_PLANNED`, `AI_ACTION_FAILED`, `AI_ACTION_FALLBACK_EXECUTED`가 기록됩니다.

### 5. 전략 자원 조달
목재·석재 부족이 주택 건설, 영토 확장, 건물 유지·복구를 직접 막고 있을 때 해당 자원의 교역 점수를 추가로 높입니다.

특히 자원 부족 압력이 큰 국가는 정규 교역과 별도로 **계절 행동을 막고 있는 목재/석재를 한 번 더 전략 조달**할 수 있습니다. Gold가 충분하지만 원자재 부족 때문에 장기간 아무 행동도 못 하는 현상을 줄이는 목적입니다. 관련 로그는 `STRATEGIC_PROCUREMENT`로 남습니다.

### 6. 건물 재활성 히스테리시스
건물 상태가 0%에 도달한 뒤 유지자원이 조금 들어왔다고 즉시 켜졌다가 다음 계절 다시 꺼지는 현상을 완화했습니다.

한 번 비활성화된 건물은 수리 진행도를 내부적으로 누적하며, **15% 이상 복구된 시점**에 다시 실제 서비스에 들어갑니다. 15% 미만의 복구는 `BUILDING_REPAIR_PROGRESS`, 실제 재가동은 `BUILDING_REACTIVATED`로 구분합니다.

### 7. 해상 활동 개발자 로그 강화
국가간 거래 로그에 `routeMode: land / sea`를 기록합니다. 해상 거래라면 `seaSteps`와 항구 출발·도착 타일도 함께 기록합니다. 해상 개척 시작 로그도 출발 항구와 해상 이동 정보를 명시합니다.

이를 통해 향후 장기 로그에서 항해 기술이 실제 교역·개척에 얼마나 사용되는지 직접 확인할 수 있습니다.

### 8. 기술 연구 속도는 유지
V0.15 장기 런에서는 약 100년대에 현재 기술 트리가 완주되었지만, Village Observer의 장기 목표는 고대에서 중세·근대·현대·미래까지 기술과 사회 시스템을 계속 확장하는 것입니다.

따라서 V0.16에서는 현재 36개 기술의 연구 속도나 연구 선택 알고리즘을 인위적으로 늦추지 않았습니다. 기술 콘텐츠는 이후 버전에서 시대별로 계속 확장합니다.

## V0.15 핵심 변경사항

### 1. 지도 분석 레이어
지도 탭에서 세계를 단순 지형도 외의 방식으로 관찰할 수 있습니다.

- **기본 지도**: 기존 지형·국경·정착지 표시
- **인구 지도**: 타일별 실제 Person 거주 인구를 보정 히트맵으로 표시
- **자원 지도**: 식량·목재·석재 중 하나를 골라 타일의 자연자원 잔존 비율을 표시
- **건물 상태**: 건물의 평균 상태와 비활성 비율이 나쁠수록 강하게 표시
- **물류 지도**: 최근 60일 내부 물류 이동을 선으로 표시

레이어를 바꿔도 국경과 정착지 표시는 다시 그려져 국가별 공간 구조를 놓치지 않도록 했습니다.

### 2. 백과의 건설기간 표시 방식 수정
기존처럼 여러 건물의 시간을 상단에 한꺼번에 적지 않습니다.

각 건물 항목에 **`기본 공사기간`**을 개별 표시합니다. 실제 공사기간은 주민 노동력, 공사 정체, 기술 효과에 따라 더 길어질 수 있습니다.

V0.15에서 추가된 항구의 기본 공사기간은 150일이며, 학당은 135일의 기본 공사기간을 명시합니다.

### 3. 사회 복구 체제
V0.14에서는 건물 대부분이 비활성화되고 목재가 고갈된 국가가 문제를 인식하면서도 정상 행동을 실행할 수 없어 수십 년 동안 회복하지 못하는 사례가 있었습니다.

V0.15에서는 여러 위기 신호가 겹치면 국가가 **복구 체제**로 전환합니다.

복구 체제에서는 다음 행동이 우선됩니다.
- 신규 영토 확장 억제
- 주민의 낮은 효율 **수작업 식량·목재·석재 채취**
- 비활성 건물이 있는 정착지로 성인 노동력 재배치
- 붕괴 잔해 또는 비활성 비핵심 건물을 해체해 건설 자원의 약 30% 회수
- 경작지와 주택 등 핵심 기반시설 우선 건설·복구

복구 체제는 무조건적인 구제 장치가 아닙니다. 주민과 자연자원 자체가 부족하면 여전히 인구가 감소하거나 국가가 소멸할 수 있습니다.

### 4. 붕괴 국가의 연구 속도 보정
기반시설이 크게 비활성화되거나 복구 체제에 들어간 국가는 Knowledge 획득 효율이 감소합니다.

따라서 실제 생산·주거 기반이 붕괴한 국가가 인구는 급감하면서도 기술만 정상 속도로 발전하는 현상을 완화했습니다.

### 5. 수역 4단계
기존의 단일 `water` 지형은 내부적으로 다음 수역으로 분류됩니다.

- **호수**: 맵 가장자리와 연결되지 않은 내륙 수역
- **연안**: 육지에 바로 접한 바깥 수역
- **해양**: 연안에서 더 떨어진 수역
- **대양**: 가장 깊은 외해

기존 MapData v1의 `water` 타일도 불러온 뒤 자동으로 분류되므로 V0.14 맵 파일을 그대로 사용할 수 있습니다.

물 타일은 국가 영토로 점령하지 않습니다.

### 6. 항해 기술 3단계
신규 기술 3개가 추가되어 전체 기술 수가 36개가 됩니다.

- 🛶 **연안 항해**: 호수·연안 통과, 항구 해금, 짧은 해상 교역·개척
- ⛵ **항해술**: 해양 통과, 더 긴 해상 교역·개척
- 🧭 **원양 항해**: 대양 통과, 가장 긴 해상 항로

항해 기술이 있더라도 국가간 해상 교역은 양국에 활성 **항구**가 있어야 가능합니다.

### 7. 항구와 바다 건너 개척
신규 건물 **항구(⚓)**를 추가했습니다.

- 비용: 목재 36 · 석재 14 · Gold 12
- 기본 공사기간: 150일
- 해상 교역의 출발·도착 노드
- 항해 기술을 보유한 국가는 적절한 해안 정착지에 항구를 자동 건설할 수 있음

항구를 보유한 국가는 자신의 항해 단계에서 통과 가능한 수역을 건너 새로운 육지를 개척 후보로 평가합니다. 바다 건너 개척에 성공하면 상륙 정착지에 개척 거점과 항구가 함께 설치되어 본토와의 해상 물류 연결 가능성을 확보합니다.

### 8. 식량 편중 교역 완화
V0.14 장기 로그에서는 국가 AI가 목재 부족을 최우선 문제로 인식하는 상황에서도 실제 국가간 거래가 사실상 식량에 집중되는 현상이 확인되었습니다.

V0.15에서는 거래 후보 평가에 다음을 더 강하게 반영합니다.
- 국가 전체의 목표 재고 대비 부족량
- 판매국의 국가 전체 잉여량
- 실제 교역소/항구 타일의 현지 재고와 저장 여유
- 운송비와 Gold 예산

목재와 석재의 구조적 부족 점수를 높였으며, 식량 비축이 충분한 국가는 식량 거래의 상대 우선도가 내려갑니다.

### 9. 교역 정책과 계절 행동 분리
`TRADE`가 매 계절의 유일한 행동을 차지하면서 다른 발전 행동을 막는 현상을 완화했습니다.

이제 AI가 교역을 전략적으로 우선할 때는 **45일짜리 배경 교역 정책**을 켜고, 같은 계절에 유지·식량·주거·방어·확장 중 하나의 물리적 행동도 별도로 선택합니다.

따라서 교역 중심 국가도 교역을 계속하면서 주택을 짓고 기반시설을 관리할 수 있습니다.

### 10. 개발 데이터 확장
V0.15 스냅샷/개발 로그에는 다음 진단값이 추가됩니다.

- 복구 체제 여부
- 수작업 식량·목재·석재 누적량
- 해체로 회수한 목재·석재와 해체 횟수
- 항해 단계와 항구 수
- 식량·목재·석재별 실제 교역 횟수
- V0.15 수역·복구·교역 모델 정보

### 11. 캐시 방지
GitHub Pages에 새 `index.html`을 덮어쓴 뒤 브라우저가 이전 버전 HTML을 오래 유지하는 문제를 줄이기 위해 HTML에 `no-cache / no-store / must-revalidate` 메타 설정을 추가했습니다.

> GitHub Pages/CDN 자체 캐시는 별도 계층이므로 배포 직후에는 플랫폼 캐시가 잠시 남을 수 있지만, 브라우저 측 이전 HTML 재사용 가능성은 줄어듭니다.

## V0.14 핵심 변경사항

### 1. 자연형 기본 지도 생성
기본 새 세계가 더 이상 각 타일의 지형을 독립적으로 뽑지 않습니다.

- 평야·초지·숲·암지·산·물이 주변 타일과 연속성을 가지는 **덩어리형 자연 지형**으로 생성됩니다.
- 맵 에디터와 같은 생성 원리와 자원 생성 규칙을 사용합니다.
- 생성된 세계에는 Seed와 생성 방식이 기록됩니다.
- 시작 국가는 단순 무작위 육지가 아니라 **Spawn 생존 적합도**를 평가해 배치합니다.

Spawn 평가는 다음 요소를 봅니다.
- 시작 타일의 식량 자연회복력
- 주변 2칸의 식량 생산 잠재력
- 가까운 숲의 목재 접근성
- 암지·산의 석재 접근성
- 주변 통행 가능한 육지 수
- 해안/고립 위험
- 다른 Spawn과의 거리

### 2. 맵 에디터 MapData 불러오기
지도 화면의 `맵 파일` 버튼에서 **Village Observer Map Editor의 MapData v1 JSON**을 바로 불러올 수 있습니다.

맵 파일에서 그대로 적용되는 정보:
- 맵 가로·세로 크기
- 모든 타일의 지형
- 각 타일의 초기 `resourceCap`
- 각 타일의 실제 초기 `resources`
- Spawn A/B/C/D 위치
- 맵 이름과 Seed

MapData에는 국가 이름이나 AI 성격을 고정하지 않습니다. 같은 지도를 반복 실행하면서 Spawn 위치에 서로 다른 국가/AI 조합이 들어가는 실험이 가능합니다.

게임 시작 전 다음 오류는 차단합니다.
- 타일 데이터 수 불일치
- 알 수 없는 지형
- 잘못된 자원 수치
- Spawn 4개 미만
- 물 위 Spawn
- 맵 밖 Spawn
- Spawn 중복

생존 적합도가 낮은 Spawn은 경고를 표시합니다.

### 3. 초기 국가 붕괴 완화
V0.13에서는 일부 국가가 시작 1개월 만에 장기 개척을 시작한 뒤 식량과 노동력을 잃고, 이주가 연쇄적으로 발생하는 사례가 확인되었습니다.

V0.14에서는 단순 초기 자원 보너스 대신 의사결정 구조를 조정했습니다.

#### 첫 개척 준비
- 영토가 1칸인 국가는 **최소 61일**이 지나기 전에는 첫 개척을 시작하지 않습니다.
- 시작 타일의 장기 식량 생산성이 낮으면 더 높은 식량 비축을 요구합니다.
- 초반 또는 식량 압박 상태에서는 확장 후보 중 **평야·초지와 식량 생산력이 높은 타일**을 더 선호합니다.

#### 자원 고갈을 반영하는 1년 전망
기존 AI 전망은 최근 생산 추세가 계속된다고 보는 성격이 강해, 초기 자원이 풍부할 때 미래 식량을 지나치게 낙관적으로 계산할 수 있었습니다.

V0.14에서는 현재 영토의 식량 자연회복량, 인구 소비량, 식량 자원 고갈도를 함께 보아 지나치게 낙관적인 식량 전망을 낮춥니다.

#### 실행 불가능한 AI 행동 억제
- 실제로 접근 가능한 교역국이 0이면 `TRADE` 점수를 크게 낮춥니다.
- 주택 건설에 필요한 기본 목재·석재가 부족하면 `HOUSING`을 크게 낮춥니다.
- 첫 개척 준비기간에는 `EXPAND`를 억제합니다.
- 첫 정착지의 식량이 부족하면 `FOOD` 대응을 더 우선합니다.

#### 식량난 이주 지연
식량이 잠시 부족하자마자 주민이 빠르게 빠져나가 생산력이 더 악화되는 현상을 완화했습니다.

- 식량 비축 7일 미만 상태가 누적되어야 장기 식량 위기로 봅니다.
- 초기 18일 동안은 외부 이주가 발생하지 않습니다.
- 이후 위기가 길어질수록 이주 확률이 서서히 증가하며 상한이 있습니다.
- `foodCrisisDays`를 스냅샷 CSV에 기록합니다.

### 4. 기술 트리: 고대~중세 시대감 재정비
V0.14의 기술 시대 범위는 **고대~중세 수준**을 기본으로 합니다.

현대적인 인상을 줄 수 있던 명칭을 다음처럼 재정의했습니다.
- `공중위생` → **우물과 배수**
- `공학` → **토목술**
- `도시화` → **도시 발달**
- `교육제도` → **학당 교육**

의학 같은 근현대적 별도 기술은 추가하지 않았습니다.

### 5. 기술 선행관계와 비용 재조정
초반 기술 하나를 얻는 데 너무 오래 걸리고, 행정 발전이 상업 트리에 과하게 종속되던 구조를 완화했습니다.

주요 변경 예시:
- **행정제도**: `기록법 + 측량`
- **도량형**: `교역 관습 + 기록법`
- **화폐제도**: `시장 + 도량형`
- **윤작**: `농경 + 기록법`

기초·중간 기술의 Knowledge 비용도 전반적으로 낮췄습니다. 후반 기술은 여전히 장기 발전 목표가 되도록 상대적으로 높은 비용을 유지합니다.

### 6. 신규 기술 8개
전체 기술 수가 **25개 → 33개**로 늘었습니다.

- 🌲 **임업**: 숲 목재 자연회복 +30%, 목재 채취 +6%
- 🧂 **식량 보존**: 계절 식량 부패 -40%
- 🕊️ **사절단**: 접촉국과 장기 관계 관리
- 🏫 **학당**: 학당 건물과 학자 직업 해금
- 🔥 **봉수와 파수**: 넓어진 영토의 방어·감시 강화
- 🏰 **축성술**: 방책의 방어 기여 강화
- 📜 **상법**: 교역 비용 감소, 회당 교역량 증가
- 🧱 **공공사업**: 신규 건설 기본기간 단축

### 7. 실제 주민 기반 연구 — 학자
Knowledge가 인구 수에 거의 자동으로 비례하는 현상을 줄이기 위해 연구 전문화를 추가했습니다.

- `학당` 기술을 연구하면 학당 건물을 건설할 수 있습니다.
- 활성 학당이 있고 식량 사정이 충분하면 호기심이 높은 성인 주민 일부가 **학자**가 될 수 있습니다.
- 학자는 일반 생산 노동 대신 연구 활동을 하며 더 많은 Knowledge를 만듭니다.
- 따라서 높은 연구력을 얻으려면 실제 노동력 일부를 연구에 배치하는 기회비용이 생깁니다.
- 기존 `기록법 / 학술 전통 / 학당 교육`의 전국 Knowledge 배율은 이전보다 완만하게 조정했습니다.

## 맵 에디터
ZIP 루트의 `map_editor.html`은 독립 실행형 맵 에디터입니다.

- 자연형 맵 생성

에디터가 만든 JSON은 V0.15 게임 지도 화면의 `맵 파일` 버튼에서 그대로 불러올 수 있으며, 물 타일의 세부 수역은 게임에서 자동 분류합니다.

## 핵심 구조

`World → Nation → Settlement → Person`

- **Person**: 실제 개별 주민
- **Settlement**: 타일 단위 정착지와 현지 경제
- **Nation**: 국가 AI, 기술, Gold, 교역, 전략
- **World**: 지도, 시간, 국가 간 상호작용

## 시간

- 1 tick ≈ 1일
- 1계절 = 30일
- 1년 = 120일
