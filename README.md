# Village Observer V0.26

Village Observer는 실제 주민(Person)의 생활과 선택이 **Settlement → Nation → World** 변화로 이어지는 browser-based bottom-up 사회 시뮬레이션입니다.

V0.26은 V0.25의 60년 장기주행에서 확인된 문제를 처리하는 **성능·UI·관찰 안정화 패치**입니다. 인구·질병·아사·확장·건설/유지보수 밸런스는 최대한 그대로 유지하고, 더 큰 인구와 더 긴 시간대를 감당할 수 있도록 내부 계산과 화면 갱신 구조를 정리했습니다.

---

## 1. 성능 최적화

### 타일별 주민 인덱스

기존에는 `tileResidents(tileId)`를 호출할 때마다 해당 국가의 전체 Person 배열을 다시 검색했습니다. 이 함수는 물류, 건설, 유지보수, 이주, 출산, UI 등에서 매우 자주 호출되기 때문에 인구가 커질수록 비용이 급격히 증가했습니다.

V0.26에서는 국가별로 실제 Person을 유지한 채 다음 인덱스를 사용합니다.

- 생존 주민 목록
- `homeTileId → Person[]` 인덱스
- 출생/사망/이주 시 자동 무효화
- 반환값은 기존처럼 독립 배열로 제공하여 기존 로직의 동작을 보존

로컬 마이크로 벤치마크에서는 800명의 Person을 50개 정착지에 분산한 반복 조회가 V0.25 대비 약 **25배** 빨라졌습니다. 실제 전체 시뮬레이션 개선폭은 다른 시스템 비용도 포함하므로 이보다 작습니다.

### 장기 내부 경로 캐시

V0.25의 동일 국가 내부 경로비 캐시는 짧은 주기로 폐기되어, 큰 국가에서는 동일한 정착지 쌍의 경로를 반복 계산하는 경우가 많았습니다.

V0.26에서는 다음이 바뀔 때까지 동일 경로 결과를 재사용합니다.

- 영토 구성
- 활성 도로 위치
- 활성 항구 위치
- 도로/항해 관련 기술

대형 영토 반복 경로 조회 마이크로 벤치마크에서는 약 **9배**의 속도 향상을 확인했습니다.

### 전체 헤드리스 벤치마크

개발 환경의 15년 헤드리스 진행 기준으로 V0.25 약 19.9초 → V0.26 약 14.8초로 약 **25% 단축**되었습니다. 브라우저와 세계 상태에 따라 실제 개선폭은 달라질 수 있습니다.

## 2. 성능 수치 상시 표시

모든 탭에서 공통 헤더 아래 상태줄에 다음 값을 계속 표시합니다.

- 현재 배속
- `SIM ms/batch`
- `ms/day`
- `UI ms`
- 현재 가장 큰 계측 항목(`HOT`)

예:

`×10 · SIM 420ms/batch · 42ms/day · UI 2.1ms · HOT logistics 130ms`

SIM batch가 550ms를 넘으면 상태줄 색을 경고색으로 표시합니다.

## 4. 스크롤 초기화 수정

V0.25에서는 실행 중 UI가 주기적으로 다시 렌더링되면서 모든 탭에서 사용자의 스크롤 위치가 위쪽으로 돌아가는 현상이 있었습니다.

V0.26에서는 렌더 직전과 직후에 다음 위치를 보존합니다.

- 전체 페이지 스크롤
- 현재 main view 스크롤
- 국가 상세 패널
- 개발자 로그
- 연대기

국가 카드 영역은 국가 구조가 바뀌지 않은 경우 전체 DOM을 매번 재생성하지 않고 기존 카드를 갱신합니다.

---

## 5. 국가 경계 시인성 개선

국가가 커진 뒤에도 경계가 읽히도록 지도에 별도 국경선을 추가했습니다.

- 서로 다른 국가 사이: 얇은 짙은 회색/검정 윤곽선
- 국가와 중립지/해안 경계: 동일한 외곽선
- 선택 국가: 기존 국경 위에 해당 국가색으로 더 굵은 강조선
- 기존 지형과 국가색 오버레이는 유지

따라서 국가색을 지나치게 진하게 만들어 지형을 가리는 대신 **경계선 자체를 분명하게 표시**합니다.

---

## 6. 개척률 관측값 추가

60년 목표를 눈대중이 아니라 수치로 확인할 수 있도록 다음 값을 스냅샷/개발자 로그에 추가했습니다.

- `claimableNaturalTiles`: 직접 개척 가능한 자연 육지 타일 수
- `claimedNaturalTiles`: 그중 현재 국가가 점유한 타일 수
- `claimedNaturalShare`: 개척 비율
- `remainingClaimableNaturalTiles`: 남은 개척 가능 타일 수

물 타일과 통행 불가능 타일은 개척 가능 자연 타일에서 제외합니다.

---

## 7. CSV 관측 데이터 보강

V0.25 스냅샷 객체에는 평균 Hunger가 존재했지만 최종 CSV 열에서 누락되는 경로가 있었습니다.

V0.26 CSV에는 다음을 명시적으로 추가합니다.

- `avgHunger`
- `claimableNaturalTiles`
- `claimedNaturalTiles`
- `claimedNaturalShare`
- `perfSimMs26`
- `perfRenderMs26`
- `perfMsPerDay26`
- `perfSpeed26`

기존 V0.25 노동/유지보수 열도 그대로 유지합니다.

---

## 8. 건설 완료 로그 보정

V0.25에서 새 건설 프로젝트 일부가 `elapsedCalendarDays`를 실제 경과일이 아니라 세계 절대 날짜처럼 기록할 수 있었습니다.

V0.26에서 새로 시작되는 건설/주택 개축 프로젝트는 정확한 `startCalendarDay25`를 기록하여 완료 시 실제 달력 경과일을 계산합니다.

---

## 9. V0.25 밸런스 유지

이번 버전에서는 다음 핵심 밸런스를 의도적으로 변경하지 않습니다.

- 연령별 질병사 기본률
- Hunger 100 즉시 아사
- 출산 구조
- 개척 거점 수용력 3명
- 건설 총 노동량
- 분기 유지보수 노동량 0.5%
- Condition 변화 공식
- 원격 유지보수 AI
- 개척 속도/후반 포화 구조

V0.26의 목적은 **같은 사회를 더 빠르고 안정적으로 관찰하는 것**입니다.

도시집약형의 수도 집중 행동은 V0.27에서 별도 개편합니다.

## 12. 다음 버전 방향

V0.27의 중심은 **Urbanization & Settlement Hierarchy**입니다.

- 도시집약형 AI를 실제 수도/대도시 집중형으로 변경
- 정착지별 도시 성장/중심성 지표
- 직업·주거·상업·교통을 반영한 내부 이주
- 미래의 도시권/행정권 통합을 위한 데이터 기반

V0.28부터 자원 일반화와 철 경제로 이동합니다.
