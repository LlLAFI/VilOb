# Village Observer V0.23

Village Observer는 실제 주민(Person)의 생활과 선택이 **Settlement → Nation → World**의 변화로 이어지는 bottom-up 자율 사회 시뮬레이션입니다.

V0.23은 V0.22의 19×19 장기 검증(약 61년)을 바탕으로 만든 **사회·경제 안정화 패치**입니다. 새 시대를 크게 여는 버전이라기보다, V0.24 이후의 시간체계·철기 시대 확장을 안정적으로 받치기 위한 기반 정리 버전입니다.

핵심 변경점은 다음과 같습니다.

1. **실제 사망 결과를 반영하는 인구변천 연구 AI**
2. **세계 전체 → 국가 → 정착지 인구통계**
3. **Gold 장기 순환 보정**
4. **가격 해석용 경제 지표 추가**
5. **SIM/UI 성능 계측 + 상세 이벤트 로그 경량화**

V0.22의 장거리 접촉·교역, 고출산·고사망 인구동학, 병렬 개척 시각화, 파란색 물류 지도는 그대로 유지됩니다.

---

## 1. 인구변천 연구 AI

V0.22에는 이미 다음 기술의 생존 효과가 구현되어 있었습니다.

- `CART`
- `ROADS`
- `FRONTIER_LOGISTICS`
- `FOOD_PRESERVATION`
- `SANITATION`
- `PUBLIC_WORKS`
- `EDUCATION`
- `URBANIZATION`

하지만 61년 장기 검증에서는 대부분의 국가가 이 기술 계통에 충분히 진입하지 못해, **고출산·고사망 → 고출산·저사망** 전환이 제대로 발생하지 않았습니다.

V0.23의 연구 AI는 국가 전체 식량량만 보지 않고 최근 약 8년의 실제 사건을 함께 봅니다.

- 출생 수
- 아동 사망
- 질병·쇠약 사망
- 아사

질병·아동사망이 많으면 `SANITATION / PUBLIC_WORKS / EDUCATION / URBANIZATION`과 그 선행기술의 연구 우선순위가 상승합니다.

아사가 많으면 `FOOD_PRESERVATION / CART / ROADS / FRONTIER_LOGISTICS`와 그 선행기술의 우선순위가 상승합니다.

또한 20~30년대 이후에도 핵심 생존 기술이 지나치게 늦어지는 경우 완만한 시대 진행 보정이 적용됩니다. 기술을 강제로 지급하지 않고 **AI의 선택 가중치만 조정**합니다.

> V0.23은 출생률 자체를 다시 크게 올리는 패치가 아닙니다. V0.22의 높은 출생률을 유지하면서 기술 발전으로 사망률이 내려갈 가능성을 높이는 패치입니다.

## 2. 세계 전체 인구통계

국가의 `사회` 탭에서 통계 범위를 다음처럼 선택할 수 있습니다.

1. **세계 전체**
2. **현재 국가 전체**
3. **해당 국가의 특정 정착지**

각 범위에서 실제 살아 있는 Person을 직접 집계해 표시합니다.

- 총인구
- 남녀 성비
- 평균연령
- 10세 단위 인구 피라미드
- 직업 분포

V0.23까지 나이 증가·출생·사망 판정은 연 단위로 이루어지므로, 인구 피라미드의 코호트 불연속 문제는 완전히 해결하지 않습니다. 이 부분은 V0.24의 360일제·출생일 기반 시간모델에서 근본적으로 수정할 예정입니다.

## 3. Gold 순환 보정

V0.22 장기 검증에서는 세계 Gold가 장기적으로 감소하고 일부 국가에 크게 편중되는 현상이 확인되었습니다.

교역 자체는 세계 Gold를 보존하지만 다음 활동은 Gold를 시스템에서 소비합니다.

- 건설
- 개척
- 토지 개발
- 건물 고도화
- 축제

V0.23에서는 아직 개인 재산·임금 경제를 도입하지 않고, 이를 위한 중간 근사로 **국내 경제 환류**를 추가합니다.

매년 다음 요소를 바탕으로 소량의 Gold가 국고로 돌아옵니다.

- 생산 가능한 성인 인구
- 상인
- 시장·교역 시설
- 최근 실제 교역량
- 건설·개척·축제 등 최근 공공지출의 일부

공공지출이 전액 즉시 복구되는 것은 아니며, 환류량에는 상한이 있습니다. 따라서 Gold sink는 계속 존재하지만 V0.22보다 장기적인 통화 고갈 위험이 완화됩니다.

최종 V0.23에서는 건설·토지개발·건물 고도화처럼 `payBuild()`를 거치는 지출을 이벤트명으로 추정하지 않고 **실제 Gold 결제 순간에 기록**합니다. 직접 건설과 프로젝트 건설 사이의 누락·중복 가능성을 줄이기 위한 마감 보정입니다.

국가별로 다음 누적값을 기록합니다.

- `lifetimePublicSpending`
- `lifetimeCirculationRevenue`
- 최근 연간 환류량

Telemetry 이벤트:

- `FISCAL_CIRCULATION`

## 4. 가격 해석 UI

목재·석재의 세계 총량이 늘어도 가격이 반드시 크게 하락하는 것은 아닙니다.

현지 가격은 기존처럼 다음 조건의 영향을 받습니다.

- 해당 정착지 재고
- 저장용량 대비 비축률
- 건설·생산 수요
- 최근 거래
- 지역별 공급 차이

V0.23의 국가 `경제` 화면에는 식량·목재·석재별로 다음 정보를 함께 표시합니다.

- 국가 총량
- 1인당 보유량
- 저장용량 대비 비율
- 국가 내 정착지의 평균 현지 가격

평균 현지 가격은 단순히 모든 영토 타일을 동일하게 평균하지 않고, **실제 주민이 살거나 건물이 존재하는 정착지 타일**을 우선 집계합니다. 가격 공식 자체를 크게 재작성하지 않고, 관찰자가 가격 변화의 이유를 더 쉽게 해석할 수 있도록 했습니다.

## 5. 성능 계측과 로그 경량화

V0.22 19×19 검증의 체감 성능:

- 약 10년: 렉 없음
- 약 36년: 약간의 렉
- 약 61년: 36년과 비슷한 수준
- 일시정지 시 렉 사라짐

V0.23은 실행 중 병목을 분리할 수 있도록 런타임 상태에 다음 값을 표시합니다.

- `SIM xx.x ms` — 현재 배속의 시뮬레이션 batch 계산 시간 이동평균
- `UI xx.x ms` — 렌더링 시간 이동평균

또한 routine telemetry의 상세 이벤트 보존창을 **최근 약 30년**으로 줄였습니다.

- 최근 상세 이벤트는 유지
- 수동 메모는 유지
- 오래된 세계의 연간 요약(`yearlySummaries`)은 계속 유지
- snapshot 계층 압축 정책도 유지

이를 통해 과거 전체 상세 이벤트 배열을 반복 검색하는 일부 기존 시스템의 후반 비용과 메모리 사용량을 줄입니다.

성능 최적화는 V0.23에서 종료하지 않고 앞으로 모든 버전에서 상시 점검합니다.

## 6. V0.22 시스템 유지

### 인구

- 높은 출생률
- 높은 영유아·아동 질병사망
- 지역 식량 부족에 의한 실제 아사
- 노환 사망
- 생존기술에 의한 사망 위험 감소

### 개척

- 실제 Person Pioneer
- 지역 잉여 성인 pool
- 2~3명 개척대
- 성향별 개척 임계값
- 성숙 정착지 기반 병렬 개척
- 위험 변경만 제한적으로 자동 보강

### 장거리 접촉·교역

`미발견 → 문명 발견 → 시장 정보 → 실제 교역 가능`

`ENVOYS`, `LONG_DISTANCE_TRADE`, 항해 기술 등에 따라 발견·시장·교역 거리가 단계적으로 늘어납니다.

### 물류 지도

내부 물류는 하늘색~파란색 계열, 국가 간 교역은 기존 자원별 색을 사용합니다.

## 7. V0.23 개발 회귀 테스트

### 문법

- HTML 내부 30개 script 추출
- 전체 `node --check` 통과

### 19×19 20년 스모크 테스트

고정 난수 개발 실행에서:

- V0.23 직렬화 정상
- 인구/개척/경제 진행 정상
- Gold 환류 누적 정상
- telemetry/snapshot 정상 진행

최종 고정 난수 회귀(seed 12345)의 20년 누적 Gold 환류는 세계 전체 약 **72.24G**였고, 추적된 누적 공공지출은 약 **450.28G**였습니다. 이 값은 밸런스 목표가 아니라 환류·공공지출 추적 시스템이 실제로 작동하는지 확인하기 위한 회귀값입니다.

### 연구 AI 압력 테스트

35년 시점에 높은 아동·질병 사망과 아사를 인위적으로 준 테스트에서 연구 선택이 다음 생존 기술 경로를 실제로 우선했습니다.

`기록법 → 농업/석공 → 수레/도로 → 관개 → 정착지 계획 → 우물과 배수`

이후 학당·행정·교육 계통도 선택 가능한 상태로 이어졌습니다.

### V0.23 최종 마감 회귀

후보 빌드 복구 후 최종 마감 과정에서 다음을 다시 확인했습니다.

- HTML 내부 30개 script 전체 `node --check` 통과
- 19×19 20년 실제 브라우저 smoke test 정상
- 세계/국가/정착지 사회 통계 UI 정상 렌더
- 경제 가격 해석·Gold 환류 UI 정상 렌더
- SIM/UI 런타임 계측 실제 값 갱신 확인
- V0.23 저장 → 재로드 시 인구·Gold·접촉망·환류 상태 보존
- V0.22 저장 → V0.23 로드 시 인구·Gold·접촉망 보존 및 V0.23 환류 상태 정상 부착
- 60년 장기주행에서 상세 routine event 30년 보존창 정상 작동 확인
- 60년 시점 생존기술 연구 경로가 실제로 `ROADS / FRONTIER_LOGISTICS / SANITATION / PUBLIC_WORKS` 방향으로 이동하는 것 확인

이 장기주행 수치는 밸런스 목표값이 아니라 V0.23의 의도한 시스템이 자연주행에서도 연결되는지 확인하기 위한 회귀 결과입니다.

### 저장 호환
