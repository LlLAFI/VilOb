# Village Observer V0.33F5A4
## Codex Rebuild + Ancient Production Facilities V1

기준 버전: **V0.33F5A3**  
패치 성격: 백과 구조 재정리 + 고대 농업/임업/채석 생산시설 개편 + A3 전시 병력 목표 정합성 수정

---

## 1. 패치 목표

V0.33F5A4는 오래된 버전별 설명이 계속 누적되면서 실제 현재 규칙과 백과 설명이 어긋나기 시작한 문제를 정리한다. 동시에 관개·윤작과 임업처럼 전국에 추상적인 생산 배율을 더하던 기술 효과 일부를 **실제 건설·개축 가능한 생산시설**로 옮긴다.

이번 버전의 핵심 목표는 다음과 같다.

- 백과를 과거 버전별 패치 설명이 아니라 **현재 적용 중인 규칙** 중심으로 재구축한다.
- 건물의 실제 상위 티어 관계를 백과에서 직접 확인할 수 있게 한다.
- 관개·윤작에 중복 적용되던 경작 관련 수치 효과를 제거하고 **고대 농장** 개축으로 대체한다.
- 임업 기술에 실제 **고대 제재소** 생산시설을 추가한다.
- 고대 채석장을 모든 통행 가능한 육지에 건설 가능하게 하되 암지·산의 효율 우위를 크게 유지한다.
- 고대 방책 설명을 현재 전쟁·점령 시스템의 실제 효과와 일치시킨다.
- V0.33F5A3에서 확인된 `fieldTarget > activeTarget` 전시 병력 목표 오류를 수정한다.

이번 패치에서는 Frontier 지형별 Gold 가격, F5A 50/25/25 개척 회계, 문화 규칙, F5 통화가격 anchor는 변경하지 않는다.

## 2. 백과 전면 재구축

### 2.1 현재 규칙만 표시

기존 백과는 여러 버전의 `renderCodex()` wrapper가 차례대로 설명 상자를 삽입하는 구조였다. 그 결과 이미 폐기된 규칙과 최신 규칙이 한 화면에 함께 나타나는 문제가 있었다.

V0.33F5A4에서는 최종 백과 렌더러를 하나로 통합하고 다음 탭만 사용한다.

1. **건물**
2. **생산·자원**
3. **물류·도로**
4. **경제·시장**
5. **군사·전쟁**
6. **사회·문화**
7. **기술**

버전별 변경 이력은 백과가 아니라 게임 내 패치노트와 README에서 확인한다.

### 2.2 오래된 설명 정리

대표적으로 다음 오래된 표현을 제거했다.

- 과거 3단계 도로 설명 → 현재 **단일 물리 도로, 경로비 ×0.62**로 통일
- 과거 식량 소비량 0.36/0.25 → 현재 **15세 이상 0.42 / 0~14세 0.30**으로 수정
- 과거 고대 방책의 단순 “방어점수 +5” 설명 → 현재 점령 저항과 방어화력까지 설명
- 과거 관개/윤작의 중복 생산·노동자 효과 → 제거 후 고대 농장 해금으로 대체

## 3. 건물 업그레이드 계보 UI

백과의 **건물 탭에서 건물을 클릭**하면 해당 건물부터 이어지는 상위 티어를 표시한다.

현재 표시되는 주요 계보는 다음과 같다.

- 고대 주택 → 고대 연립주거 → 고대 집합주거
- 고대 경작지 → **고대 농장**
- 고대 교역소 → 고대 상단 회관
- 고대 시장 → 고대 대시장
- 고대 채석장 → 고대 전문 채석장

각 티어는 별도의 정식 건물 카드로 표시하며 다음 정보를 함께 보여준다.

- 해금 조건
- 배치 조건
- 건축공간 사용량
- 건설/개축 비용
- 필요 노동량
- 저장공간
- 근무 인원
- 주요 효과
- 분기 유지보수

상위 티어가 없는 건물은 현재 건물 정보만 표시한다.

## 4. 관개·윤작 재설계

### 4.1 제거된 중복 효과

기존 코드에서는 V0.33E1의 기술 통폐합 이후 `CROP_ROTATION`이 `IRRIGATION`으로 canonicalize되었지만, 오래된 생산식이 두 기술을 각각 다시 확인하고 있었다.

그 결과 관개·윤작 하나만 연구해도 다음 효과가 동시에 겹칠 수 있었다.

- 평야·초지 식량 +18%
- 평야·초지 식량 +12%
- 경작지 식량 +5%
- 경작지 노동자 +1
- 경작지 노동자 +2

V0.33F5A4에서는 위 효과를 **실제 생산식과 기술 설명 모두에서 제거**했다.

기존 `농업`의 다음 효과는 유지한다.

- 고대 경작지 해금
- 기본 식량 채취 +8%

### 4.2 새로운 관개·윤작 효과

관개·윤작의 공식 효과는 이제 하나다.

> **고대 경작지 → 고대 농장 개축 해금**

즉 기술 연구만으로 전국 평야의 생산성이 즉시 상승하지 않는다. 실제 정착지가 자원과 노동력을 투자해 농업시설을 개축해야 한다.

## 5. 신규 건물: 고대 농장

ID: `ancient_farm`

고대 농장은 **직접 신축하지 않고 기존 고대 경작지를 개축**해서 만든다.

### 기본 규격

- 해금: 관개·윤작
- 이전 티어: 고대 경작지
- 건축공간: **2.0**
- 개축비: **목재 18 / 석재 8 / Gold 4**
- 필요 노동량: **260 성인 노동일**
- 농부 슬롯: **10명**
- 식량 저장: **80**
- 목재 저장: 4
- 석재 저장: 2
- 도구 저장: 4

건축학 보유 시 기존 건설 체계와 동일하게 목재·석재 비용 할인을 받을 수 있다.

### 생산효과

건물 상태가 100%일 때:

- 타일 식량 자연회복 **×1.60**
- 실제 식량 채취 **×1.25**

건물 상태가 낮아지면 기존 건물 condition 체계에 따라 효과도 감소한다.

고대 경작지는 계속:

- 농부 슬롯 7명
- 식량 자연회복 ×1.35
- 식량 채취 최대 ×1.10

을 사용한다.

### AI

AI는 관개·윤작을 보유하고 다음과 같은 경우 고대 농장 개축을 검토한다.

- 첫 고대 농장이 아직 없고 국가가 일정 규모 이상 성장했을 때
- 식량 비축일이 낮아졌을 때
- 평균 Hunger 압력이 높을 때
- 인구 규모에 비해 고대 농장 수가 부족할 때

개축은 일반 건설 프로젝트 슬롯과 실제 Gold/자원/노동을 사용한다.

## 6. 신규 건물: 고대 제재소

ID: `sawmill`

### 임업 기술 변경

기존 임업의 전국적 `목재 채취 +6%` 효과는 제거했다.

임업은 이제 다음 두 효과를 갖는다.

- **고대 제재소 건설 해금**
- 소유 숲의 목재 자연회복 **+30%**

### 제재소 기본 규격

- 건축공간: **1.8**
- 건설비: **목재 22 / 석재 8 / Gold 5**
- 필요 노동량: **280 성인 노동일**
- 목수 슬롯: **4명**
- 목재 저장: **120**
- 석재 저장: 8
- 도구 저장: 8

### 실제 생산효과

제재소는 단순 전국 보너스가 아니다.

- 실제 `목수` Person이 제재소 슬롯에 배치되어야 한다.
- 해당 목수가 제재소가 있는 타일에서 목재를 채취할 때 건물 상태 100% 기준 **최대 ×1.45**의 제재 효율을 받는다.
- 타일의 실제 목재 재고를 채취하므로 목재를 무에서 생성하지 않는다.
- 숲은 임업 기술의 자연회복 +30%와 결합해 가장 유리한 제재소 입지가 된다.

AI는 소유 타일 중 실제 목재량과 지형을 평가하며 숲을 강하게 우선한다.

## 7. 고대 채석장: 전 지형 건설 + 지형 효율 차등

기존 AI는 사실상 암지·산만 고대 채석장 후보로 사용했다.

V0.33F5A4에서는 **모든 통행 가능한 소유 육지**를 고대 채석장 후보로 허용한다.

다만 실제 채석 효율은 지형에 따라 크게 다르다.

| 지형 | 고대 채석장 석재 채취 배율 |
|---|---:|
| 평야 | ×1.08 |
| 초지 | ×1.08 |
| 숲 | ×1.06 |
| 암지 | ×1.40 |
| 산 | ×1.55 |

따라서 평지에서도 소규모 석재 산업은 가능하지만, 암지·산이 여전히 압도적으로 좋은 입지다.

### 고대 전문 채석장

고대 전문 채석장은 기존처럼 암지·산 중심의 상위 티어다.

| 지형 | 전문 채석장 배율 |
|---|---:|
| 암지 | ×1.65 |
| 산 | ×1.80 |

기존의 여러 세대에 걸쳐 누적되던 `×1.22`, `×1.20` 추가 배율은 제거하고 A4의 지형별 공식 하나로 통합했다.

## 9. A3 전시 병력 목표 정합성 수정

V0.33F5A3 자연주행에서 다음과 같은 불가능한 목표가 관측되었다.

- active target 3
- field target 4

야전병력은 실제 현역 Person의 일부이고 최소 1명의 core garrison을 남겨야 하므로 이 상태는 성립할 수 없다.

V0.33F5A4에서는 전시 목표에 다음 invariant를 적용한다.

> **fieldTarget ≤ activeTarget - 1**

처리 순서:

1. 준비 단계가 요구한 field target 확인
2. 가능한 경우 active target을 먼저 늘려 field 목표를 수용
3. 동원가능 인구 cap 때문에 active를 더 늘릴 수 없으면 field 목표를 가능한 범위까지 낮춤
4. 이미 진행 중인 A3 세이브의 비정상 war target도 로드 시 자동 보정

보정 발생 시:

`WARTIME_TARGET_INVARIANT_REPAIRED33F5A4`

이벤트를 남긴다.
