# Village Observer V0.17

Village Observer는 실제 주민(Person)의 생활과 선택이 정착지(Settlement), 국가(Nation), 세계(World)의 변화로 이어지는 **bottom-up 자율 사회 시뮬레이션**입니다.

V0.17은 V0.16의 84년 장기 관찰과 이후 설계를 바탕으로, 단순한 국가 단위 자원 관리에서 한 단계 더 내려가 **정착지별 지역 가격, 제한된 시장 정보, 타일별 건축 공간, 실제 토지 개발, 건물 세대 교체**의 기반을 추가한 버전입니다. 동시에 지도 조작·정착지 관찰·스크롤 유지 등 관찰자 UI를 크게 보완했습니다.

기본 세계는 V0.16과 동일한 **19×19 / 4개 국가**이며, 기존 36개 기술의 연구 속도와 기술 트리 구조는 이번 버전에서 변경하지 않았습니다.

## V0.17 핵심 변경사항

### 1. 선택 타일에서 자연자원 잔량 확인

지도에서 육지 타일을 선택하면 이제 두 종류의 자원을 구분해서 볼 수 있습니다.

- **채취 가능한 자연자원**: 그 땅에 실제로 남아 있는 식량·목재·석재와 자연 최대량
- **문명 비축량**: 해당 정착지가 이미 채취해서 저장해 둔 식량·목재·석재

Gold 광맥이 있는 경우 자연 Gold 잔량도 별도로 표시됩니다.

중립 타일에서도 자연자원은 관찰자에게 표시됩니다. 이는 관찰자 UI 정보이며, 해당 정보가 자동으로 모든 문명에게 공유되는 것은 아닙니다.

---

### 2. 지도 카메라와 상단 UI 개선

기존의 실질적 기능이 없던 `선택 국가` 버튼을 실제 카메라 기능으로 바꾸고 지도 조작을 확장했습니다.

- 마우스 휠: 커서 위치 중심 확대/축소
- 마우스 드래그: 카메라 이동
- 모바일 한 손가락 드래그: 카메라 이동
- 모바일 두 손가락 pinch: 확대/축소
- 확대 범위: 약 **×0.65 ~ ×8**
- `전체 보기`: 지도 전체가 보이는 기본 위치로 복귀
- `선택 국가`: 현재 선택 국가의 영토가 화면에 들어오도록 자동 확대·중앙 정렬
- 확대 배수와 지도 범례 pill의 텍스트 중앙 정렬 개선

짧은 클릭/탭은 기존처럼 타일 선택으로 작동합니다.

### 3. 정착지 상세보기

`국가 → 정착지`의 기존 정착지 카드 목록은 유지됩니다.

카드를 누르면 아래에 해당 정착지의 상세 패널이 열립니다.

표시 내용:

- 건축 공간 사용량 / 현재 개발량 / 현재 기술에서의 잠재량
- 현지 식량·목재·석재 가격
- 주거 / 저장 / 상업 / 생산 압력
- 자연자원 잔량
- 주민 직업 구성
- 건물 수
- 진행 중 일반 건설
- 진행 중 토지 개발
- 진행 중 건물 개축
- `지도에서 보기`

지도와 국가/정착지 화면을 서로 오가기 쉽게 만들었습니다.

## 지역경제

### 4. 정착지별 지역 가격

V0.17에는 세계 전체가 공유하는 하나의 시장가격이 없습니다.

각 정착지는 다음 세 자원의 **자체 현지 가격**을 가집니다.

- 식량
- 목재
- 석재

가격은 약 5일 단위로 조금씩 조정되며 주로 다음 조건에 반응합니다.

- 현지 비축량과 저장 여유
- 주민 수와 식량 비축일
- 현재 건설에 필요한 목재·석재
- 해당 타일에 남은 자연자원
- 최근 실제 교역량

따라서 같은 해에도 서로 다른 도시에서 같은 자원의 가격이 다를 수 있습니다.

가격은 순간적으로 목표값으로 튀지 않고 점진적으로 이동합니다.

---

### 5. 모든 국가가 모든 가격을 알지 못함

지역 가격이 생겼지만 국가 AI가 전 세계의 가격표를 직접 읽지는 않습니다.

각 국가는 `marketKnowledge`에 **실제로 접촉해서 알아낸 외국 시장 정보**만 저장합니다.

예:

> 벨른 (12, 8) · 석재 0.74G · 37일 전 정보

현재 규칙:

- 처음 도달 가능한 외국 시장을 조사하면 해당 자원 가격을 알아냅니다.
- 첫 가격 확인 자체에서는 즉시 거래하지 않습니다.
- 이후 거래 판단에는 기억하고 있는 판매지 가격을 사용합니다.
- 정보가 오래되면 실제 현재 가격과 달라질 수 있습니다.
- 약 **240일 이상 오래된 가격정보**는 다시 시장 접촉을 통해 갱신해야 합니다.
- 실제 거래가 이루어지면 양측의 시장정보가 갱신됩니다.

`국가 → 교역` 아래에는 **이 국가가 알고 있는 외국 시장 정보**와 정보의 나이가 표시됩니다.

이 시스템은 향후 Person 단위 상인 기억과 실제 차익거래로 확장하기 위한 첫 단계입니다.

---

### 6. 실제 거래 가격과 개발자 로그

거래는 기존의 자원 부족·잉여·교역 경로 판단을 유지하면서 다음을 추가로 고려합니다.

- 구매지의 현지 가격
- 구매자가 알고 있는 판매지 가격
- 운송비
- 전략적 자원조달 압력
- 실제 구매 가능한 Gold 예산

개발자 로그의 `TRADE`에는 V0.17에서 다음 정보가 추가됩니다.

- `unitPrice`
- `knownPriceAge`
- `buyerLocalPrice`
- `sellerMarketPrice`

시장 가격을 처음 알아낸 경우 `MARKET_INFO_DISCOVERED` 이벤트가 기록됩니다.

## 건설 공간과 도시 발달

### 7. 타일별 건축 공간

모든 육지 타일에는 이제 건물을 넣을 수 있는 공간이 존재합니다.

건축 공간은 세 값을 구분합니다.

1. **사용 중 공간**: 현재 건물 footprint의 합
2. **현재 개발된 공간**: 지금 실제 건설에 사용할 수 있는 공간
3. **잠재 공간**: 현재 기술 수준으로 개발 가능한 최대 공간

대략적인 지형별 초기 / 장기 잠재 상한은 다음과 같습니다.

| 지형 | 초기 개발 공간 | 장기 지형 상한 |
|---|---:|---:|
| 평야 | 13 | 22 |
| 초지 | 12 | 21 |
| 숲 | 10 | 20 |
| 암반 | 9 | 17 |
| 산악 | 6.5 | 14 |

기술이 발전했다고 공간이 자동으로 증가하지 않습니다.

기술은 **개발 가능한 잠재 상한을 열어 줄 뿐**이고, 실제 사용 가능한 공간은 문명이 토지 정비에 투자해야 증가합니다.

현재 잠재 공간에는 측량, 건축, 공학, 도시계획, 도시화 기술이 단계적으로 영향을 줍니다.

---

### 8. 실제 토지 개발 프로젝트

빈 공간이 부족하고 기술적으로 더 개발할 여지가 있으면 문명은 토지 정비 프로젝트를 시작할 수 있습니다.

한 번의 개발은 최대 약 **+2 건축 공간**을 확보합니다.

기본 비용은 지형 난이도에 따라 증가합니다.

- 목재: `8 × 지형 난이도`
- 석재: `6 × 지형 난이도`
- Gold: `4 × 지형 난이도`
- 기본 공사량: `90 × 지형 난이도`

공학 기술은 개발 속도를 개선합니다.

개발은 실제 현지 노동력을 사용해 진행되고 완료되어야 공간이 증가합니다.

개발자 로그:

- `LAND_DEVELOPMENT_STARTED`
- `LAND_DEVELOPMENT_COMPLETED`

따라서 도시 성장에는 이제 다음 선택이 생기기 시작합니다.

- 주변 타일로 확장
- 현재 타일의 미개발지를 정비
- 기존 건물을 더 높은 밀도의 건물로 교체

---

### 9. 건물 footprint

건물은 이제 타일 공간을 서로 경쟁해서 사용합니다.

예를 들어 현재 주거 계열은:

| 건물 | 수용 인원 | 건축 공간 |
|---|---:|---:|
| 주택 | 4 | 1.0 |
| 연립주택 | 8 | 1.4 |
| 집합주택 | 16 | 2.0 |

창고, 시장, 교역소, 학당, 항구, 농장, 도로 등 기존 건물에도 각자의 footprint가 부여되어 있습니다.

건축 공간이 부족하면 일반 건설은 시작되지 않으며 개발자 로그에 `BUILDING_BLOCKED_SPACE`가 기록됩니다.

---

### 10. 건물 숫자 레벨 대신 실제 세대 교체

건물은 사용자에게 `주택 Lv.2`처럼 표시하지 않습니다.

V0.17에서는 우선 주거 계열부터 실제 건물 교체를 도입했습니다.

**주택 → 연립주택 → 집합주택**

- `도시계획` 기술: 주택 → 연립주택 가능
- `도시화` 기술: 연립주택 → 집합주택 가능

개축은 즉시 능력치가 오르는 업그레이드가 아닙니다.

- 기존 건물 지정
- 목재·석재·Gold 지불
- 현지 노동력 투입
- 실제 공사 진행
- 완료 후 기존 건물을 새 형태로 교체

연립주택 기본 비용:

- 목재 24
- 석재 15
- Gold 7
- 기본 공사량 150

집합주택 기본 비용:

- 목재 36
- 석재 26
- Gold 16
- 기본 공사량 220

건축 기술이 있으면 목재·석재 비용이 감소합니다.

현대의 아파트·고층 아파트·아파트 단지 등은 아직 추가하지 않았습니다. 향후 현대 기술 트리가 확장될 때 같은 **교체 공사 시스템** 위에 이어 붙일 예정입니다.

개발자 로그:

- `BUILDING_UPGRADE_STARTED`
- `BUILDING_UPGRADED`

## 정착지 수요 / 건설 압력

### 11. 왜 그곳에 그 건물을 짓는가

V0.17은 별도의 추상적인 `수요 포인트`를 누적하지 않습니다.

대신 현재 상태를 바탕으로 정착지마다 다음 **파생 압력**을 그때그때 계산합니다.

- 주거 압력
- 저장 압력
- 상업 압력
- 생산 압력

예:

- 주거 수용량이 거의 찼음 → 주거 압력 상승
- 저장고가 자주 가득 참 → 저장 압력 상승
- 실제 교역량이 많음 → 상업 압력 상승
- 현지 자원이 풍부하고 가격 신호가 큼 → 생산 압력 상승

높은 압력은 정착지의 추가 건설·개축·토지개발 판단에 반영됩니다.

개발자 로그에는 압력에 의해 실제 추가 행동이 발생한 경우 `SETTLEMENT_DEMAND_ACTION`이 기록됩니다.

이 구조는 앞으로 실제 Person의 주거 선택, 상인의 거래 실패, 물류 병목 등을 집계해 수요가 형성되는 더 bottom-up한 모델로 확장할 수 있습니다.

## 현재 의도적으로 아직 하지 않은 것

V0.17은 장기 도시·경제 시스템의 기반 버전입니다. 다음 요소는 아직 단순화되어 있거나 미구현입니다.

- 세계 공통 시장가격: 의도적으로 없음
- Person 개별 상인의 독립적인 시장기억: 아직 국가 단위 시장지식으로 근사
- 토지가격 / 지대
- 정식 용도지역(zoning)
- 모든 건물 계열의 세대 교체: 현재는 주거 계열부터 시작
- 현대 아파트·고층건물
- 실제 도로 이동시간과 통근
- 선박 Person/Entity 기반의 물리적 해상교역
- 완전한 Person 기반 소비시장
