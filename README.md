# Village Observer V0.13

Village Observer는 실제 주민(Person) 개체의 생활과 선택이 정착지(Settlement), 국가(Nation), 세계(World)의 변화로 이어지는 **bottom-up 자율 사회 시뮬레이션**입니다.

## V0.13 변경사항

### 1. 정착지 주민 수 시각화
- 국가 탭의 정착지 카드에서 주민 수를 더 크게 표시합니다.
- `👥 주민 수`, 유효 주거 수용량, 주거 점유율 바를 함께 보여줍니다.
- 수용량에 가까운 정착지는 경고 표시가 나타나며 과밀 상태는 더 강하게 표시됩니다.
- 기존의 상세 주민·행복도·식량·건물 정보는 그대로 유지합니다.

### 2. 외교형 AI의 장기 정체 탈출
V0.12 장기 데이터에서 외교형 국가는 인구와 기술은 성장했지만 영토 확장이 지나치게 느렸고, 계절 AI가 TRADE를 반복하는 현상이 확인되었습니다.

V0.13의 외교형은 여전히 **교역 우선형**이지만 다음 조건에서는 다른 해결책을 적극 검토합니다.
- 장기간 영토 확장이 정체됨
- 목재 등 구조적 자원 부족이 교역으로도 해소되지 않음
- 주거 점유율이 높음
- 교역을 여러 계절 연속 선택했지만 상황이 개선되지 않음

이 경우 EXPAND와 HOUSING의 우선도가 상승하고 TRADE 반복 점수는 완만하게 낮아집니다. 또한 실제 개척에 필요한 목재·석재·식량을 우선 예약하고, 목재가 부족할 때 시장·창고·채석장 같은 비필수 신규 공사 일부를 잠시 미뤄 개척 자원을 확보합니다. 외교형의 성격을 없애는 버프가 아니라, **교역으로 해결되지 않는 문제에 다른 수단을 선택하도록 하는 적응형 보정**입니다.

### 3. 초기 전략적 견제 시스템
본격적인 전쟁 시스템 이전 단계로 국가들이 서로의 성장을 의식하는 **전략적 경계(Strategic Concern)**를 추가했습니다.

성능을 위해 모든 국가 쌍을 상시 O(N²) 비교하지 않습니다. 각 국가는 다음 상대만 평가합니다.
- 실제 국경이 맞닿은 국가
- 최근 180일 동안 실제 교역이 있었던 국가

경계도는 다음 요소를 반영합니다.
- 상대적 인구·영토·기술·Gold를 합친 세력 차이
- 직접 국경 접촉
- 영토 및 기술 격차
- 최근 특정 국가에 대한 수입 의존도
- 기존 국가 관계
- AI 성격

경계가 높아지면:
- SECURITY 판단이 조금 상승합니다.
- 목재·석재 같은 전략 자원의 대량 수출을 완만하게 줄입니다.
- 식량은 생존 자원이므로 수출 제한이 훨씬 약합니다.
- 관계도에 작은 긴장 압력이 생깁니다.

아직 전쟁, 동맹, 제재 같은 본격 외교 시스템은 아닙니다.

### 4. 식량 밸런스 조정
V0.12 데이터에서는 국가 전체에 수백 일치 식량이 있으면서도 일부 외곽 정착지에서 기아가 발생했습니다. 따라서 전역 식량 생산량을 일괄 하향하지 않고 지역 경제를 조정했습니다.

#### 긴급 식량 수송
- 주민이 있는 정착지의 식량 비축이 **10일 미만**이면 긴급 상태로 봅니다.
- 70일을 넘게 비축한 다른 정착지에서 식량을 우선 수송합니다.
- 긴급 수송은 평시 내부 물류의 최대 **1.5배 용량**까지 사용할 수 있습니다.
- 운송 시간 자체는 아직 0일이며, 기존의 거리·지형·도로·기술에 따른 용량 계산은 유지됩니다.

#### 과잉 식량 부패
- 정착지 저장률이 **78%를 초과**하면 과잉 비축 식량 일부가 계절마다 부패합니다.
- 72% 기준 초과분의 약 **3.5%/계절**이 손실됩니다.
- 활성 곡물창고는 이 손실을 약 **55% 감소**시킵니다.
- 낮은 식량 비축 정착지는 영향을 받지 않습니다.

### 5. 기존 자원 밸런스 유지
V0.12 데이터에서 목재는 실제 국가간 전문화와 교역을 만들어내고 있었습니다. 따라서 V0.13에서는:
- 목재 자연회복량을 추가로 변경하지 않습니다.
- 석재 자연회복량도 변경하지 않습니다.
- Gold 교역 회계 방식과 수수료 보존 구조를 유지합니다.

건물 비활성화 로그를 분석한 결과 자원 부족보다 **현지 노동력 부족**이 주된 원인이었기 때문에, 건물 유지비를 단순히 더 비싸게 만드는 변경도 하지 않았습니다.

### 6. 관전성과 개발 로그
- 국가 개요에 `외교·전략적 경계` 패널을 추가했습니다.
- 전략적 경계가 높은 상대와 경계 수치를 볼 수 있습니다.
- `STRATEGIC_CONCERN_ENTER`, `STRATEGIC_CONCERN_RESOLVED`, `FOOD_SPOILAGE`, `EMERGENCY_FOOD` 관련 데이터를 개발 로그에서 추적할 수 있습니다.
- 스냅샷 CSV에 `maxStrategicConcern`, `strategicConcernTarget`, `foodSpoiled`, `emergencyFoodMoved` 열을 추가했습니다.

## 핵심 구조

`World → Nation → Settlement → Person`

- **Person**: 실제 개별 주민
- **Settlement**: 타일 단위 정착지와 현지 경제
- **Nation**: 국가 AI, 기술, Gold, 교역, 전략
- **World**: 지도, 시간, 국가간 상호작용

## 시간

- 1 tick ≈ 1일
- 1계절 = 30일
- 1년 = 120일
