# Village Observer V0.21

Village Observer는 실제 주민(Person)의 생활과 선택이 정착지(Settlement), 국가(Nation), 세계(World)의 변화로 이어지는 **bottom-up 자율 사회 시뮬레이션**입니다.

V0.21은 V0.20의 인구·노동·병렬 개척 기반을 유지하면서, 100×100 한반도 장기 테스트에서 확인된 **“인구는 늘지만 영토 순증 속도가 충분히 가속되지 않는 문제”**를 다루는 **Frontier Growth 패치**입니다.

이번 버전의 핵심 원칙은 단순히 확장 확률을 올리는 것이 아니라 다음 연결을 만드는 것입니다.

`인구 증가 → 성숙한 정착지 증가 → 실제 잉여 성인 발생 → 개척민 이동 → 새로운 정착지 → 새로운 프런티어`

---

## V0.21 핵심 변경사항

### 1. 국가 크기보다 실제 정착지의 개척 여력

V0.20에서는 국가 전체 인구와 유인 정착지 수에 따라 동시 개척 슬롯이 단계적으로 증가했습니다.

V0.21에서는 **각 정착지 자체의 상태**가 더 중요합니다. 개척 출발지는 다음을 확인합니다.

- 실제 거주 인구
- 실제 성인 인구와 Pioneer 제외 가용 성인
- 개척민을 내보낸 뒤에도 남길 최소 성인
- 현지 식량 비축일
- 활성 주거/개척 거점 존재
- 신규 변경이면 일정 정착 기간 경과
- 이미 같은 정착지에서 개척 프로젝트를 진행 중인지 여부

따라서 큰 국가라도 사람이 없는 변경 타일 수만 많다고 개척 능력이 자동으로 증가하지 않습니다.

### 2. 성숙 정착지 기반 병렬 프런티어

동시 개척 한도는 **실제로 개척민을 공급할 수 있는 성숙 정착지 수**를 중심으로 계산합니다.

- 각 출발 정착지는 동시에 하나의 프런티어 프로젝트만 담당
- 신규 변경은 곧바로 다음 개척을 반복할 수 없음
- 주민·성인·식량·정착 기간이 확보되어야 새 개척 출발지가 됨
- 전체 동시 개척은 최대 8개로 제한

AI 성향은 동일한 물리 규칙 위에서 판단 가중치만 다르게 적용합니다. 영토확장형은 프런티어를 더 적극적으로 평가하고, 도시집약형은 더 조밀한 확장을 선호하며, 자원개척형은 가치 높은 자원 방향을 더 높게 평가합니다.

### 3. 2~3명의 실제 개척민이 새 정착지에 남음

V0.20에서는 두 명이 개척대를 떠나도 성공 후 한 명만 새 정착지에 남았습니다.

V0.21에서는 **프로젝트에 참여한 실제 Pioneer가 새 정착지에 정착**합니다.

- 기본: 실제 성인 Pioneer 2명
- 출발지의 성인 잉여와 국가 인구밀도가 충분하면 3명 규모 개척대 가능
- 3명째가 추가되면 식량·목재·Gold 비용도 소폭 증가
- 성공 후 Pioneer들은 새 타일을 거주지와 근무지로 사용
- 출발지의 최소 성인 인구는 보존

이를 통해 확장 속도를 높이면서도 영토가 사람 없이 색칠되는 것을 막습니다.

### 4. 인구밀도 피드백

V0.21의 자동 개척은 국가 인구가 영토에 비해 지나치게 희박해지면 스스로 둔화합니다.

즉 개척 확률을 일괄 배수로 올리지 않고:

- 인구가 충분히 조밀함 → 여러 정착지에서 프런티어 활성화
- 영토가 인구보다 너무 빠르게 증가함 → 자동 개척 억제

구조로 변경했습니다.

출산 시스템 자체는 V0.20에서 크게 변경하지 않았습니다. 먼저 확장 모델을 조정하고 실제 장기 인구밀도 결과를 다시 관찰하기 위한 선택입니다.

### 5. 신규 변경 정착지의 실제 주민 보강

새 거점은 일정 기간 동안 인구 2~3명 수준으로 머물 수 있습니다.

V0.21에서는 국가 전체 인구밀도와 식량 상황이 충분히 좋을 때, **기존의 인구가 많은 정착지에서 실제 성인 주민 한 명이 변경으로 이주**할 수 있습니다.

- 실제 Person의 `homeTileId` / `workTileId`가 변경됨
- 인구가 충분한 정착지만 donor가 될 수 있음
- donor 정착지의 최소 주민·성인·식량을 보존
- 영토확장형·자원개척형은 매우 풍부한 인구밀도에서 한 분기에 더 많은 보강이 가능

이 이동은 `FRONTIER_REINFORCEMENT` 이벤트로 기록됩니다.

### 6. 군집형·빈 공간 우선 확장

V0.20보다 후보 타일 평가에서 **영토 연결성과 주변 정착지 지원**의 비중을 높였습니다.

주요 평가 요소:

- 4방향 아군 영토 인접 수
- 반경 2 이내 아군 영토/유인 정착지 수
- 기존 영토 사이의 빈 공간을 채우는 효과
- 중심부에서 너무 긴 돌출부를 만드는 비용
- 식량·목재·석재 자원가치
- 폐허 재정착 가치
- 이전 개척 실패 기억
- AI 성향별 자원/밀집/확장 가중치

따라서 기본적으로는 기존 영토 가까이에서 덩어리진 국경을 만들되, 자원개척형은 가치 있는 자원을 향한 돌출 확장을 상대적으로 더 허용합니다.

### 7. 변경 정착지 성숙 상태

V0.21 신규 영토는 내부적으로 설립일과 성숙일을 추적할 수 있습니다.

성숙에 필요한 요소는 실제 주민 수, 성인 수, 식량 비축, 활성 거점/주거, 정착 경과일입니다.

성숙 조건을 만족하면 `FRONTIER_SETTLEMENT_MATURED`가 기록되고, 이후 해당 정착지는 조건에 따라 새로운 프런티어의 출발지가 될 수 있습니다.

### 8. V0.20 노동·석재 구조 유지

다음 V0.20 기능은 그대로 유지됩니다.

- Person의 `homeTileId` / `workTileId` 분리
- 실제 통근
- 일반 채석장 2명 / 전문 채석장 5명 광부 슬롯
- 실제 Person 광부 고용
- 실제 30일/120일 생산량 telemetry
- 석재 가공장 수요·상류 공급 게이트
- 사회 탭의 인구피라미드·성비·직업분포
- 좋은 환경에서의 완만한 추가 출산
- 통계 `<select>` 재생성 방지

## V0.21 개발자 로그 / CSV

기존 V0.20 필드에 다음 프런티어 진단값이 추가됩니다.

- `matureFrontierSettlements`: 현재 성숙 조건을 충족한 정착지 수
- `eligibleFrontierSettlements`: 지금 실제로 새 개척을 시작할 수 있는 정착지 수
- `frontierSurplusAdults`: 출발 가능 정착지의 가용 성인 잉여
- `frontierBlockedPopulation`: 주민 부족으로 막힌 정착지 수
- `frontierBlockedAdults`: 성인 잉여 부족으로 막힌 정착지 수
- `frontierBlockedReserve`: 현지 식량 비축 부족
- `frontierBlockedAge`: 신규 거점의 정착 기간/기반 미성숙
- `frontierBlockedProject`: 이미 개척 프로젝트가 진행 중인 출발지
- `frontierBlockedNoCandidate`: 인접한 개척 가능 타일이 없음
- `frontierStarts21`: V0.21 모델에서 시작한 누적 개척 수
- `frontierClaims21`: 신규 영토 획득 수
- `frontierRecaptures21`: 폐허 재정착 수
- `frontierCancels21`: 중단된 V0.21 개척 수
- `frontierRuins21`: V0.21 실행 중 폐허화된 외곽 거점 수
- `frontierReinforcedSettlers21`: 신규 정착/보강으로 이동한 실제 주민 수
- `avgPopulationPerTerritory`: 국가 인구 ÷ 영토 타일 수

`FRONTIER_EXPANSION_STARTED`에도 출발지 인구·성인 수, 인접 영토 수, 주변 지원 영토 수, V0.21 모델 여부가 추가됩니다.

## 자연주행 회귀 테스트

개발 중 동일 난수 시드의 19×19 단기 비교에서 V0.21은 V0.20보다 빠른 초기 공간 확장을 보이면서 개척 관련 `AI_ACTION_FAILED` 없이 진행되었습니다.

별도의 20년 자연주행에서는:

- 6개 국가 생존
- 인구 181명
- 영토 51타일
- 프런티어 시작 47회
- 영토 획득/폐허 재정착 45회
- 외곽 거점 폐허 0회
- EXPAND 실행 실패 0회

를 확인했습니다.

이 수치는 고정 밸런스 목표가 아니라 **V0.21 로직이 기존 V0.20보다 빠른 프런티어 성장과 실제 인구 제약을 동시에 구현하는지 확인하기 위한 회귀 테스트 결과**입니다.

## 이후 큰 패치 축

V0.21은 합의한 장기 계획의 **A. 문명 확장 재조정**만 다룹니다.

다음 큰 축은 별도 버전으로 진행합니다.

- **B. 장거리 접촉·교역**: 발견, 시장정보, 대상로/장거리 상업, 거리비용
- **C. 자원·산업 기반**: 자원 레지스트리 일반화, 철광석→제련→철
- **D. 시간·로그·대형맵 기반**: 1년 360일, 90일×4분기, 로그 계층화/압축, 성능
- **E. 군사·전쟁**: 실제 Person 군인, 장비, 부대, 이동, 전투, 점령
- **F. 학습형 AI**: 고정 성격 + 경험으로 조정되는 정책

V0.21에서는 장거리 교역, 철, 360일제, 전쟁을 의도적으로 추가하지 않았습니다.
