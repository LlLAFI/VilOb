전체 세이브 파일은 이 브라우저에서만 읽어. 게임 실행·날짜 진행·세이브 수정 없이 구조 검증과 경량 비교용 보고서를 생성해.

선택된 파일 없음

② 검사 결과

발견된 오류·경고 (최대 100개씩)


세이브 파일 내부 용량 상위 항목


검사 범위와 제한
이 도구는 원본 JSON만 읽어 Nation–Tile–Person 관계, 국가 영토, 타일 재고, 폐허 장비 잔존 원장을 검사해. 저장 데이터를 엔진으로 재불러오거나 하루 진행하지 않으며, 장비 전량의 공식 I1 감사 함수·국가 통화의 전체 회계 감사는 실행하지 않아. JSON 파싱·브라우저 메모리 부족 오류가 발생하면 오류로 표시하며 통과로 간주하지 않아.




③ 전후 보고서 비교 (34B → 34C → 34C1)


같은 저장 상태의 이관 전 보고서와 이관 후 보고서를 선택하면 국가·타일·Person별 물리적 데이터 지문을 비교해. 검사 보고서만 선택하며 96.8MB 세이브를 다시 올릴 필요는 없어.








파일은 서버로 전송하지 않으며 원본 세이브를 덮어쓰지 않아. 브라우저가 이용할 수 있는 메모리에 따라 처리 가능 파일 크기가 달라질 수 있어. 검증 보고서는 엔티티의 이름·개인 보유 상태를 직접 출력하지 않고 개별 지문 및 집계만 기록해.
