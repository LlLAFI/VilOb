# Village Observer V0.34H1 — Map UI & Settlement Visualization V2

기준: **V0.34H0**. 날짜: 2026-10-18. 이 릴리스는 지도 표시 및 타일 상세 UI 전용 변경입니다.

## 실행

- 단독 실행: `index-standalone.html` 또는 `dist/standalone/index.html`을 PC/모바일 브라우저에서 엽니다.
- GitHub Pages: 루트 `index.html`과 **`dist/hosted/assets/`**를 동일한 상대 경로 체계로 배포합니다. `dist/hosted/index.html`은 `dist/hosted/assets/`와 같이 배포해야 합니다.
- 로컬 대용량 세이브 검사: `local-validator-h1.html` (파일을 로컬에서만 불러오는 자체 실행 검사기).
- 소스 재빌드: Node.js 18+에서 `npm run build`; 주 테스트 `npm run test:h1` 및 `python tools/browser-h1-smoke.py`.

## 주요 변경

1. **정착지 완전 외곽선**: V0.34C의 노란색 내부 경계·전체 중심점 오버레이를 교체. Settlement ID가 다르거나 외부(다른 국가/중립지/수역/맵 경계)와 닿은 모든 변을 국가색 기반 이중선으로 그림. 같은 국가의 서로 다른 정착지는 안정적인 명도 편차를 적용.
2. **약한 내부 음영**: 국가색을 낮은 투명도로 채우고 국가 경계와 Formation/시설 아이콘의 가독성을 유지.
3. **경계 모드**: `끔` / `전체` / `선택 강조`. 선택 강조는 클릭한 타일의 Settlement만 강조하고, **그 밖의 중립지·수역까지** 어둡게 처리. 중심 타일은 해당 모드에서만 표시. 중립 타일 선택 시 불필요한 강조 없음.
4. **구형 생활권 표시 UI 삭제**: V0.29 P1 `lifezone` 드롭다운 선택지, 전용 그리기, 관련 타일 안내를 제거. 실제 최신 Settlement 공동 주거/근무/경제 계산은 유지.
5. **지도 상단 수치 수정**: 인구, 생존 국가, 실제 활성 Settlement 수, 소유 영토 타일 수, 국가 국고 합계(전체 Gold와 혼동 금지).
6. **선택 타일 정리**: 지형·번호·국가·정착지·타일 실제 인구·시설 수를 기본 표시. 자원/경제, 주거/건설, 군사/전투, 개발자 진단 및 기타 상세를 접기식으로 묶음. 원본 세부값과 이동 버튼을 유지.
7. **컨트롤 정리**: 레이어별 전용 필터는 필요한 레이어에서만 표시. AI 국가 요약 카드의 여백 축소. 새로운 세계/맵 파일 가져오기, 줌/드래그/터치/핀치 유지.
8. **경계 캐시**: 월드 포인터/Settlement 소유권 변경·병합·분리 카운터로 캐시를 교체. 지도 확대 및 이동 중 경계 구성 계산을 재사용.
9. **저장·로그**: 최신 버전 식별자 `V0.34H1`, H1 로컬 세이브 키. 기존 H0/G5 저장파일 경로 지원. Devlog JSON 버전 표기만 H1로 갱신.

## 의도적으로 변경하지 않은 것

- 타일의 실제 소유권과 Settlement 병합/분할 판단, 주민/물자/건물 실제 입지, AI 확장, 직업 생산성, 기술 43개, 전쟁·장비·군사, RNG 규칙.
- F0/F1의 관측 정의·계산·위치. F0/F1 세계 탭 이동과 국가 하위 탭 재구성은 차기 H2/H3의 범위.
- Snapshot CSV V2 **1,683열**, Devlog 원본, 생존·자원·Gold 회계 검사.

- H1의 검증은 기본 19×19 및 30일 시뮬레이션과 브라우저 UI 중심. 사용자의 장기 대용량 실세이브(특히 정착지가 대량 병합된 60년+ 세계), 150년 자연주행, 배포 서버의 네트워크 환경은 추가 검증 필요.
