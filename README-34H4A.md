# Village Observer V0.34H4A — Storage Integrity & UI Polish

## 기준선

- 기준: V0.34H4. 엔진의 AI/Person/전투/자원/Gold/RNG 규칙, 43기술, CSV V2 1,683열 불변.
- H2A 정착지 유령 링크 복구, H1/H2/H3 UI, F0/F1 계측 유지.
- 단독 HTML: `dist/standalone/index.html` 또는 루트 `index-standalone.html`.
- GitHub Pages 루트 `index.html` + `dist/hosted/assets` 사용. 루트 파일만 교체해서는 안 됨.

## 변경

1. **석재 저장 관측 및 경량 진단**: `src/bootstrap/v034h4a.js`.
   - 수동 C/D2/D3 감사를 H4의 저장 용량 분류와 연결. `STORAGE_OVERFLOW` 경고는 삭제하지 않고, 상세 유형과 재고/상한/초과량을 표시.
   - 같은 패널의 **석재 저장 경량 진단 JSON 내보내기**는 초과 정착지별 실제 구성 타일의 6종 물리 재고, 건물 종류·상태, 현재 석재 용량, 주변 구조 이벤트(남아 있는 기록 한정)를 출력.
   - 소유권/정착지 토폴로지 변화 시점과 30일 간격으로 초과 기록을 관측. 이벤트는 최근 96개만 비영속 `WeakMap`에 보관하며, Devlog export에 최대 16개를 첨부. Person 별 조회나 UI render 도중 주기적 감사 실행 금지.
   - H4A 로드 이전에 생긴 석재 재고 초과의 기원은 알아낼 수 없으며, `PREEXISTING_AT_FIRST_OBSERVATION` 등으로 미상임을 표시. 신규 관측은 원인이 입고/소유권 변화라고 단정하지 않음.
   - **초과 재고 삭제/타일 간 강제 이동/저장 상한 증설 금지**. 이번 패치는 추적을 위한 관측기이며 근본 원인 수정은 후속 증거가 필요함.

2. **지도 국경**: 정착지 경계 `전체` 모드에서 서로 다른 두 국가 간 접경선을 검은색 선으로 마지막에 덧그림. 같은 국가의 정착지 경계와 `선택 강조` 모드는 기존 유지.

3. **통계 국가색**: `statsNation` 기본 선택기 왼편에 4×16px 국가 색 막대를 표시하고, 아래에 각 국가의 세로 색상 막대 + 이름이 있는 클릭 가능한 간단한 목록 제공. 기존 드롭다운과 양방향 연동, 실제 `NS.NATION_COLORS` 기준(커스텀 프로필 색 반영). 세계 범위 통계일 때만 목록 숨김.

4. **세이브/버전**: 릴리스 V0.34H4A, 전용 로컬 저장키 사용. 기존 H4/H3/H2A/H2/H1/H0/G5 저장 파일과 지원되는 로컬 이전 키를 계속 로드함. 진단 기록은 세이브에 저장하지 않음.

## 검증 정책 및 제약

`npm run build` 후 `npm test`로 필수 검사. `H4A_DAYS=30 node tests/test-h4a-parity.cjs` 등으로 동일 RNG 장기 비교. 브라우저 `python tools/browser-h4a-smoke.py` 실행(Chromium 경로는 테스트 스크립트 참고).

**미검증**: 사용자 원본 90년 Save JSON (파일이 너무 큼). H4A로 가져온 뒤 *세계 → 고급 도구 → 기존 상세 진단 → 석재 저장 경량 진단 JSON 내보내기*를 눌러 주면 현재 5개 정착지의 물리 상태만 전달받을 수 있음. H4A 설치 이전 발생한 정확한 초과 최초 시각은 과거 기록에 없으면 알 수 없음.
