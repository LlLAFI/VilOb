# Village Observer V0.32C1a

**리비전:** `tech-tree-military-activation-stats-selector-hotfix`  
**기반 버전:** V0.32C1  
**배포일:** 2026-09-26

## 1. 패치 목적

V0.32C1은 기술트리 정리, 군사시설 자연 발화 보정, 통계 드롭다운 안정화를 한 번에 적용한 보정 버전이었다. 그러나 C1의 통계 드롭다운 보호 방식이 너무 넓게 적용되어, 브라우저가 통계 `<select>`에 포커스를 유지하는 동안 `renderStats()` 전체가 반환되는 문제가 있었다.

이 구조는 원래 목표였던 “열린 드롭다운이 매 틱마다 DOM 교체로 닫히는 현상”은 피할 수 있었지만, 모바일/브라우저별 포커스 처리에 따라 통계 탭 자체의 차트와 컨트롤 갱신까지 멈출 수 있었다.

V0.32C1a는 이 부분만 안전한 방식으로 교체하는 **핫픽스**다. C1에서 승인·적용한 기술트리와 군사시설 보정은 그대로 유지한다.

## 2. 통계 탭 핫픽스

### 2.1 C1의 문제 방식

C1에서는 통계 select가 포커스된 경우 최종 `renderStats()`를 통째로 중단했다.

결과적으로:

- 선택창의 option DOM은 유지되지만,
- 차트 갱신도 멈추고,
- 통계 범위/국가/지표 상태 동기화도 멈출 수 있으며,
- 일부 모바일 브라우저에서는 통계 탭이 고장난 것처럼 보일 수 있었다.

### 2.2 C1a의 수정 방식

C1a에서는 **통계 렌더 자체를 중단하지 않는다.**

매 틱마다:

- 통계 계산은 계속 수행한다.
- 차트도 계속 그린다.
- 통계 설명과 비활성/표시 상태도 계속 갱신한다.
- 다만 현재 사용자가 열어 둔 `<select>` 하나에 대해서만 그 틱의 `innerHTML` 교체를 잠시 차단한다.

따라서 네이티브 드롭다운이 열려 있는 동안 기존 option DOM이 파괴되지 않는다.

보호 대상:

- 범위 (`statsScope`)
- 국가 (`statsNation`)
- 정착지 (`statsSettlement`)
- 지표 (`statsMetric`)
- 기간 (`statsPeriod`)
- 구형 가격 자원 선택기 (`statsResource30A`)
- 일반화 자원 선택기 (`statsResource31F`)

드롭다운이 닫히거나 다른 컨트롤로 포커스가 이동하면 별도 처리 없이 정상 렌더 경로로 돌아간다.

## 3. V0.32C1에서 유지되는 기술트리 변경

전체 39개 기술의 비용을 일괄 인하하지 않고, 설명 정합성과 일부 약한 기술만 선별 보정했다.

### 3.1 선택적 연구비 조정

| 기술 | 이전 | C1/C1a |
|---|---:|---:|
| 봉수와 파수 | 540 | **500** |
| 축성술 | 570 | **500** |
| 학당 교육 | 720 | **660** |
| 공공사업 | 700 | **660** |
| 원양 항해 | 840 | **720** |

### 3.2 중복 선행기술 정리

- 봉수와 파수: `측량 + 행정제도` → **행정제도**
- 축성술: `석공 + 정착지 계획` → **정착지 계획**
- 상법: `화폐제도 + 도량형` → **화폐제도**
- 제련: `철광 채굴 + 석공` → **철광 채굴**

상위 기술의 기존 선행조건 때문에 실제 역사 단계가 생략되는 것은 아니다.

### 3.3 설명/효과 동기화

기술창에서 실제 코드상 존재하지만 누락되어 있던 효과를 표시한다.

대표적으로:

- 농경: 고대 경작지 해금
- 관개: 경작지 노동자 최대치 +1
- 윤작: 경작지 노동자 최대치 +2
- 식량 보존: 부패 감소 + 아사 위험 감소
- 수레: 교역뿐 아니라 내부 물류 및 아사 위험 감소
- 도량형: 시장 상인 슬롯 +1
- 사절단: 문명 발견·시장 접촉 거리 증가
- 장거리 상단: 먼 시장 접촉, 교역량, 교역소 노동슬롯, 상단회관 경로
- 측량·건축술·공학·도시화: 건축공간 증가
- 행정제도: 내부 물류, 공사슬롯, 예비군 등록
- 공학: 산업/채석 시설 노동슬롯과 도로 개선
- 학당 교육: Knowledge +15%, 학자 슬롯 +2, 질병 위험 감소
- 철공: 고대 무기고 해금

## 4. 철기 유레카

기존 유레카 시스템의 연구비 25% 보너스를 이용한다. 기술 자체를 즉시 획득시키지는 않는다.

- **철광 채굴:** 자국 영토에 자연 철광맥 보유
- **제련:** 철광산 완공 + 국가 철광석 20 이상
- **철공:** 제련소에서 철을 최초 생산하거나 이미 생산된 철을 보유

철광 자원이 실제로 있는 국가가 자연스럽게 철기 체계에 먼저 진입하도록 하는 구조다.

---

## 5. 축성술 버프

축성술을 단순 방어점수 기술이 아니라 군사 인프라 기술로 강화했다.

축성술 보유 시:

- 방책 총 방어 기여도 **+4.0/개**
- 방책 목재·석재 건설비 **-15%**
- 방책 총 건설 노동량 **-20%**
- **고대 훈련장 해금**
- 향후 V0.32E 야전 요새화 효율 보너스의 기반 기술로 사용 예정

기본 방책 노동량 자체를 전역 수정하지 않고, 축성술을 가진 국가의 신규 공사에만 적용한다.

## 7. 군사시설 자연 발화 보정

V0.32C 실제 장기주행에서 92년까지 현역과 철산업이 존재했음에도 병영/훈련장/무기고가 모두 0으로 남은 문제를 C1에서 보정했고 C1a에서도 그대로 유지한다.

### 7.1 전략 공사 슬롯

첫 군사시설이 완전히 준비된 경우:

- 일반 계절 건설보다 먼저 착공을 시도한다.
- 공사 한도 직전이라면 군사시설용 슬롯 1개를 예약할 수 있다.
- 긴급 식량, 심각한 주거/개척, 핵심 방어, 전략 철산업은 이 예약보다 우선한다.
- 기존 공사가 끝나 슬롯이 비면 즉시 군사시설을 재평가한다.

관련 이벤트:

- `MILITARY_SLOT_RESERVED32C1`
- `MILITARY_FACILITY_ACTIVATED32C1`

### 7.2 보존형 군사 재정

병영·훈련장·무기고는 철산업과 같은 개념의 전략 공동재정을 이용한다.

1. 정착지 시장의 유동성 준비금을 제외한 잉여 Gold 계산
2. 같은 국가의 다른 정착지 시장 잉여도 필요 시 동원
3. 가능한 한 국가 Treasury 전략 준비금 보존
4. 기존에 실제로 존재하는 Gold만 이동
5. 기존 건설비 지불 경로로 최종 결제

Gold는 새로 생성되지 않는다.

관련 관측 필드:

- `militaryFacilityTarget32C1`
- `militaryFacilityBlocker32C1`
- `militaryFacilityFunding32C1`
- `militaryFacilityGoldNeed32C1`
- `militaryFacilityReservedSlot32C1`

### 8.2 브라우저 표적 검증

확인 항목:

- 통계 탭 정상 진입

- 통계 지표 select에 포커스를 둔 채 틱 실행 후에도 **동일 option DOM 객체 유지**
- 자원 선택기에 포커스를 둔 채 틱 실행 후에도 포커스/선택값 유지
- 범위 선택기에 포커스를 둔 채 틱 실행 후에도 통계 렌더 지속
- 50회 연속 일일 렌더 중 통계 select 포커스 유지
- 브라우저 page error: **0개**
