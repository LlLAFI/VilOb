# Village Observer V0.35G1A — Construction Speed Rebalance

기준선 **V0.35G1**. G1A는 합의된 **건설 속도 수치 두 개만** 변경하는 소규모 패치입니다. 기술 연계 지역 보정 확장은 차기 **V0.35H**로 보류합니다.

## 실제 변경 값

| 건설 항목 | V0.35G1 | **V0.35G1A** |
|---|---:|---:|
| 일반 신축·주택 개축·시설 특화 기본 건설력 | 하루 0.25 | **하루 0.80** |
| 파견 건축가 현장 근무 배율 | ×2.5 | **×3.0** |
| 기본 작업 주기 | 3일 | 3일 (유지) |
| 성인 1명당 Settlement 보정 | +5% | +5% (유지) |
| Settlement 지역 보정 상한 | +25% | +25% (유지) |
| 건축가 파견 재검토 | 30일 | 30일 (유지) |
| 토지정비 기본 진척 | 1 작업주기당 0.55 | 0.55 (유지) |

* 신축·개축·시설 특화: `3 × 0.80 × (1 + min(0.25, 유효 성인 수 × 0.05)) × (현장 건축가 있음 ? 3.0 : 1.0)`을 **3일 작업 주기마다** 적용합니다. 예: 유효 성인이 없으면 주기당 2.4, 지역 보정 상한을 채우면 3.0, 여기에 건축가 1명이 현장 근무하면 9.0 유효 진척량입니다.
* 토지정비: 기존 별도 `0.55 × 동일 지역 보정 × (건축가 현장 근무 시 3.0)` 규칙입니다. 따라서 토지정비의 기본 속도는 인상되지 않고 건축가 **배율만** 바뀝니다.
* 정규 `totalLabor25` 노동량과 건물별 비용, 슬롯, Person 건설 노동 제거, 건축가 실제 파견/이동·복귀, 유지보수·전쟁·점령·세금·물자/Gold 회계 및 AI 결정은 V0.35G1 그대로입니다.
* **V0.35H 예정**: 지역 보정 상한을 향후 기술로 확장하는 설계. **G1A에는 포함되지 않았습니다.** 기술 수는 43개 그대로입니다.

## 빌드·배포

- 오프라인 실행: `index-standalone.html` 또는 `dist/standalone/index.html`.
- GitHub Pages: 루트 `index.html`과 `dist/hosted/assets/`를 함께 올리거나 `.github/workflows`의 기존 방식대로 `dist/hosted/` 디렉터리를 배포합니다. 루트 `index.html`을 **단독으로만** 복사하면 호스팅에서 자산이 누락될 수 있습니다.
- 소스는 이전 G1 `src/bootstrap/v035g1.js`를 그대로 보존하고, `tools/35g1a-rebalance.mjs`로 빌드 시 두 수치와 릴리스/세이브 메타데이터만 변환합니다. 보호된 C1H 169개 레거시 블록은 SHA 변경 없음.
- 소스 재현: `npm run build`; 체크: `npm test`; 수치 전용: `npm run test:35g1a`; 360일 주행: `V35G1_DAYS=360 node tests/test-35g1.cjs`.

## 세이브 호환성과 진단

- G1A 세이브의 `version`은 `V0.35G1A`, 로컬 키는 `village-observer-v035g1a`로 구분됩니다.
- **G1 및 G 세이브 가져오기 지원**. 기존 G1 로컬 키가 있다면 신규 G1A 키가 아직 없을 경우 불러오기 대체 경로를 사용합니다. G1의 진행 중 건설 노동량, 건축가 파견 상태, 진척 통계를 그대로 유지하며, 패치 후의 **새 작업 주기부터** G1A 배율이 적용됩니다.
- 세계 > 고급 도구의 `35G1A 추상 건설·건축가 JSON`으로 새 계수를 내보낼 수 있습니다. **보고서 내부 `format`은 이전 `vilob-v035g1-construction-v1`로 유지**해 G1 분석기와 필드 호환성을 보존합니다. `version`·파일명은 G1A입니다.
- Snapshot CSV 1,683열 유지, 보호 블록 169개 SHA 일치, 43개 기술 유지. 나머지 일반 경제·Person/노동·군사 시스템의 규칙과 별개입니다.

## 제한 사항

- G1과 G1A는 공사 완공 시점이 달라 AI/난수 호출 경로가 갈라질 수 있습니다. 동일 연차의 국가 성장 및 SIM/Wall 수치 차이는 건설 속도 변경만의 직접 효과로 단정할 수 없습니다.
- 29년 G1 실행의 **원본 세이브 파일은 제공되지 않았으므로**, 그 동일 세계에서 G1A로 이어지는 자연주행은 검증하지 못했습니다. 대신 G1형 합성 세이브의 이관 및 독립 360일 자연주행을 테스트했습니다.
- 실제 PC/모바일 브라우저 수동 플레이 및 25~75년 장기 자연주행은 사용자 검증이 필요합니다.
